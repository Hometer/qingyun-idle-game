# 后期战斗数值校准

日期：2026-09-27。阶段 3 增量，回应后期秘境攻防血量级偏低的反馈。

## 现状与目标

旧配置中，问道云海到鸿蒙源海的敌人依次为攻 64／88／112／136，气血 480／640／800／960，按固定步长增加。角色、装备、地图怪物也沿用小数值体系。因此只提高秘境怪物会直接破坏原有可达性。

从第 4 境起，战斗攻、防、气血按 `1.25^(境界序号-3)` 放大；前 3 境保持原值。角色全部基础属性、装备与功法效果先合并再放大；地图主线、支线和秘境敌人按其开放境界放大。该倍率只作用于战斗属性，资源产速、价格、掉落、回合数和存档字段不变。长期历练的护阵防御加成也按当前境界放大。破岳诀等面板所写的是基础加成，背包装备切换提示改为计算当前实际属性变化。

四处高阶秘境再提高原始敌人强度，使同档武器、防具和佩饰能险胜，裸装难胜。每处每日一次、失败无奖励的规则不变。

## 兼容与验证

敌人和角色数值由当前配置实时计算，没有新增存档字段。旧存档的境界、装备、首通、秘境使用次数和历史战报保持原样；后续预览与战斗采用新配置。已经发生的战报不重算。

自动化新增检查：前 3 境数值不变，四处高阶秘境按境界倍率显示；各处同档装备可胜、裸装难胜；预览与实际结算一致；新战报导出再导入保持结果。现有逐日长线测试仍覆盖普通与可胜挑战路线。实际玩家 6～8 周体验和真机操作继续留阶段 3 总体验收。
