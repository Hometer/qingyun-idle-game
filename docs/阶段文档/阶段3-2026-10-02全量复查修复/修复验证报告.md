## 兼容与限制

保持 schema v18、现有 API 请求/响应、资源和奖励数值、成长倍率 1.22、单次离线最多 12 小时、每日一次 42～56 天和二次允许更快的口径。没有迁移技术栈、删除测试/功能/玩家数据、创建收费云资源或部署上线。

IndexedDB 继续保留 `current/backup/meta`，新增 `generationHighWater` 辅助记录；缺记录兼容旧档，已有坏记录不当成新档。角色本身损坏仍需导出或确认恢复，元数据修复不会把坏角色假装修好。整数代次耗尽时拒绝写入下一代，保持当前记录。

费用预留属于保守预算保护。供应商结果未知时不能自动当免费；需要人工核对供应商账单后处理。确认 usage 后先写累计费用再移除预留，两步间崩溃可能暂时重复占用预算，避免少计。当前只验证单服务进程，跨多个实例共享锁与限流留上线阶段。
