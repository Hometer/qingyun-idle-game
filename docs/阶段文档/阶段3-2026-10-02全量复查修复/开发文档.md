## 持久化和兼容

存档继续使用现有 IndexedDB 数据库，保留 current、backup、meta，增加仅保存代次高水位的辅助记录，不清库。角色导入/恢复与元数据修复保留人工确认。合法旧版本继续兼容；损坏的当前版本拒绝运行并允许导出原档。冲突重读失败单独提示，不伪装成新角色。

费用继续保留现有 `spend.json`，新增同目录预留账本。预留先写成功才能请求模型；确认 usage 后先写累计费用，再移除预留。两步间崩溃最多保守重复占用，不少计费用。未知结果预留持续占用预算，不能因重启自动释放。账本及密钥仍处于被 Git 忽略的服务端目录。当前单实例部署范围保持；多实例共享锁在上线阶段另行验收。

模型接口路径、请求字段、响应 `source/event_id/title/body/options` 保持兼容。错误继续返回统一 error 结构；供应商失败、无 Key、预算拦截和总体截止返回明确 `source=template`。业务结算始终由确定性引擎执行。
