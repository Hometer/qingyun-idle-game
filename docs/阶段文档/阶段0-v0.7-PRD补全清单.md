## 必须问（本轮 1 个）

### 问题 1：v0.7 内容量与首轮数值基线是否按推荐推进？
- 为什么重要：决定本版交付范围与所有数值配置，直接影响开发文档与实施。
- 选项：A 按推荐全部采纳（两次筑基小进阶 + 一张三节点地图 + 一次结丹试炼，数值用 R37～R40 首轮基线）　B 调整内容量（加/减节点或试炼）　C 调整部分数值
- 推荐：**A**。范围聚焦、已做过可达性核算（试炼五波后剩 19 气血、新节点按现有装备可达），先按基线开发，再据引擎模拟结果微调。
- 不选的后果：若内容量不定，开发范围会漂移；若数值不定，只能先做配置化占位，拖慢本版闭环。
