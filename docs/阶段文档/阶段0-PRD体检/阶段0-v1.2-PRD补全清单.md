# v1.2 境界扩展 PRD 补全清单

> 对象：`docs/PRD/PRD-修仙放置游戏-v1.2-二十境.md`。2026-09-27。状态：总体范围缺口已关闭。产品经理已明确“20 个大境界、每境 10 层、10 层后突破”，无需重复询问。

## 必须问

- 无。前述层数、总境界数和晋级规则已由产品经理确认。

## 已按推荐写入的默认项

| 缺口 | 当前处理 | 理由 |
| --- | --- | --- |
| “十层”和“圆满”是否是两个节点 | 同一个节点，十层即圆满 | 避免每境意外变成十一层 |
| 四界分界与名称 | 暂不定义，也不写入现阶段解锁规则 | 旧资料只有“四界”数量，没有各界名称和边界 |
| 旧档中间层具体映射与 200 层数值 | DeepSeek 先出映射及模拟，确保旧进度不降、路线可达 | 属于需验证的实施基线，不能凭空给最终数值 |
| 终点行为 | 第 20 境十层不自动重置 | 轮回须另立规则 |
| 真实玩家/真机/部署 | 留最终总体验收 | 沿用产品经理既定节奏 |

## 版本冲突处理

- v0.2 的“四界二十一境”由 2026-09-27 确认的“二十境”取代；四界是否继续保留及其边界暂不影响境界顺序，不按猜测实现。
- v0.3～v1.1 文档提及的“本版终点”只描述各历史版本当时的可玩上限；当前 v1.1 代码仍停在金丹一层，新 PRD 为后续开发目标。
