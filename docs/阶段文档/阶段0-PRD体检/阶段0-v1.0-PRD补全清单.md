## 必须问（本轮 1 个）

### 问题 1：v1.0 内容量与首轮数值是否按推荐范围推进？
- 选项：A 按推荐（一座炼器台 + 一种玄铁 + 精钢剑/玄铁甲两件配方，数值用 R49～R50 基线）　B 仅一件装备　C 指定调整件数/属性/成本/玄铁来源。
- 推荐：**A**。两件装备覆盖武器与护甲，玄铁来自秘境与镇压，复用现有材料体系，闭环清晰且不失控。
- 不选的后果：选 B 减少装备取舍；选 C 需重算玄铁来源与「不炼器也能通关」的平衡。（可回复“按推荐”。）
