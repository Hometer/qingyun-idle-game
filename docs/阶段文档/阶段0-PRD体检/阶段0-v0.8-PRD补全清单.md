## 必须问（本轮 1 个）

### 问题 1：v0.8 内容量与首轮数值是否按推荐范围推进？
- 选项：A 按推荐（两级藏经阁 + 破岳诀/聚元诀 + 一个辅修位，先用 R41～R42 基线）／B 缩小范围（一级藏经阁同时解锁一本新功法和一个辅修位）／C 指定要调整的数量或数值。
- 推荐：**A**。这组内容决定开发量、资源消耗与流派平衡，同时覆盖资源积累和战斗准备，不新增地图、材料或模型调用；数值先用程序模拟核对。
- 不选的后果：选 B 会减少不同路线的对照，选 C 需要重算解锁成本和两条路线的可达性。（可以回复“按推荐”。）

## 可默认（已写入 PRD，确认范围时一并确认）

| 缺口 | 默认值 | 理由 |
| --- | --- | --- |
| 藏经阁是否直接产资源 | 不产资源，只负责解锁新书与辅修 | 保留修炼室、聚灵阵的价值，避免无来源的被动收益 |
| 主辅是否可同时用同一本 | 不可；选择另一槽已装备的书时主辅互换 | 避免同书叠加，切换结果清楚且不丢原配置 |
| 首次研习与切换费用 | Lv1 免费；Lv2/Lv3 继续按旧 5/15 残页；切换免费 | 延续已有功法升级习惯，不给旧玩家增加迁移成本 |
| 辅修效果 | 各书主修新增效果的 50%，逐项列于 R42 | 足以看见变化，同时让主修保持主要取舍 |
| 在途长期任务 | 沿用启动时快照，新配置仅作用于新任务 | 继承 v0.5 的一次结算与不可追改规则 |
| 多存档位 | 本版不做 | 路线图规定仅在确有玩家需求时纳入，真实试玩留总体验收 |
| 模型、数据与上线 | 沿用现有本地存档和 AI 文案边界，不新增费用 | 新规则可在既有引擎内完成 |
