## 必须问（本轮 1 个）

### 问题 1：v0.9 内容量与首轮数值是否按推荐范围推进？
- 选项：A 按推荐（三个秘境：灵药谷/古修遗迹/幽窟险境，每日各一次，AI 进入叙事，数值用 R46 基线）　B 缩小范围（两个秘境、每日各一次）　C 指定调整数量/强度/奖励/是否用 AI 叙事。
- 推荐：**A**。三个秘境覆盖低/中/高三档风险与灵草/残页/灵石三种奖励主题，确定性战斗不新增概率；AI 叙事复用现有管线、每日最多三次，不新增模型机制。
- 不选的后果：选 B 会减少风险梯度；选 C 需要重算强度与可达性。另请明确：**秘境进入叙事是否仍用 AI 写**（复用现有管线）还是先用静态模板；推荐复用 AI，成本影响很小。
