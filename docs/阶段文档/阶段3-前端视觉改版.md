# 青云修仙录前端视觉改版

日期：2026-09-27。阶段 3 增量。目标：让桌面与手机页面有清晰的修仙题材视觉和操作层级，保留现有游戏功能与存档。

## 视觉方向

- 自有的“山海夜色＋宣纸内容”风格：深松绿山景信息区、暖白内容卡、朱砂操作色与金色细节。山景使用内联 SVG 和 CSS 绘制，没有外部图片或字体依赖。
- 标题用中文宋体系统回退，正文用系统无衬线字体；主次字号、卡片间距、边框和阴影统一。
- 桌面采用左侧导航与宽内容区，手机采用图标加文字的底部导航；保留深色模式，减少动态效果设置仍生效。

## 页面与交互

- 全站资源栏改为四项常用资源卡，其他资源可展开；收益领取、天气星象、每日目标仍可见。
- 增加页面标题和说明，卡片标题和重点卡片样式统一；新手目标改为可展开摘要。
- 历练页先展示地图、难度和怪物，再展示持续历练与秘境；背包先展示装备，洞府先展示建筑。
- 建角页改为双栏题材封面和命盘表单；手机改为上下布局，保留所有选项与隐私说明。

## 验证

前端 175/175、后端 20/20 测试通过；类型检查、Lint 和生产构建通过，Lint 仍有一条既有 Hook 依赖警告。浏览器实测 390、768、1280、1440px 的五个主页面，均无横向溢出；建角页桌面/手机、深色模式、角色创建和刷新后存档恢复已检查。证据见 `docs/evidence/阶段3-前端视觉改版/`。

真人视觉偏好和物理真机操作仍由产品经理后续体验确认；本次没有改动战斗、奖励和后端 AI 规则。
