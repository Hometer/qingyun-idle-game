## 2. 子阶段 C：引导与结果

### R02 首玩目标卡
- 上下文派生 `targets`：由 `state` + `firsts` 判定四步完成状态（不靠文字日志猜测）：
  1. 领取一次收益 → `firsts.settledOnce`（`settleNow` 时置真）。
  2. 首次小进阶 → `realm` 达到 qi2 及以上。
  3. 击败并镇压首个节点 → `firsts.suppressedFirstNodeOnce`（引擎已置）。
  4. 查看一次劫势 → `firsts.viewedTribPreviewOnce`（修炼页渡劫预览渲染时用 effect 置真）。
- `Shell` 顶部显示目标卡：未完成项显示状态 + 直达按钮（切到对应入口）；④在炼气圆满前标"后续目标"；全部完成可折叠。不发资源。

### R03 随机道号
- 创建页加"随机道号"按钮，本地词表组合（如 `青/白/玄/云/霜/剑/道/尘/月/松 + 子/真人/散人/道人`），可连续换，不改灵根与初始资源。

### R13 首次数据说明
- 创建页顶部展示：进度存本机、换设备需导出；AI 际遇发送事件类型/道号/灵根/境界/地图/两条修行摘要/选项含义给国内模型，完整存档不发送；可选 AI 文案或仅用模板。
- 首次进入（无存档）或旧档升级后展示一次（localStorage `qingyun_notice_shown` 标记）。

## 3. 子阶段 D：记录、图鉴、世界观、设置

### R12 修仙录时间线
- 人物页新增"修仙录"区（或独立入口），按时间倒序展示 `state.milestones`（类型、事件名、时间）。
- `milestones` 为空（旧档迁移）时显示"此前记录未收录"，不编造。

### R16 小图鉴
- 人物页"图鉴"入口，按已解锁内容展示：地图（已解锁节点）、敌人（已通关）、装备（inventory）、功法（techniqueLevel>0）、建筑（buildings>0）。未解锁显示"尚未遇见"占位，不剧透数值。

### R17 世界观短文案
- 洞府页顶部、历练页两张地图标题下，各配一段准确、易读的半文半白环境文案（写死在 `labels.ts` 或组件内）。

### R14 存档设置
- 人物页设置区：显示存档版本（schemaVersion）、最近发起导出时间（localStorage `qingyun_last_export`）、"恢复导入前存档"按钮（`loadBackup` + `replaceSave` + 确认）。
- 导入/重置说明与影响文案补全。

### R15 主题与减少动效
- 人物页设置区：主题三档（浅色/深色/跟随系统）+ 减少动效开关。
- `<html>` 挂 `dark`（深色）/`reduce-motion` 类，`globals.css` 用 CSS 变量实现两套配色；偏好存 localStorage，刷新保持；不影响数值与结算。

## 4. 验收（剩余子阶段）
1. 任意操作（战斗/际遇/渡劫/进阶）后出现结果面板，写清消耗与获得，可关闭。
2. 新角色出现四步目标卡，随操作推进、可直达、④圆满前为后续目标、完成后折叠；不发资源。
3. 随机道号可反复换；数据说明准确（含 AI 最少信息、仅用模板开关）。
4. 际遇选完显示故事结果与准确奖励。
5. 修仙录时间线随操作记录、刷新保留、旧档不编造；图鉴只显示已解锁内容；洞府/地图有氛围文案。
6. 设置区可看版本/最近导出时间、恢复导入前档；主题三档与减少动效可用且刷新保持。
7. `tsc`、引擎测试、`next build` 全绿；375px + 桌面浏览器走查。
