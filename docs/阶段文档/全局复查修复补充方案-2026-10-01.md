# 全局复查修复补充方案（P2 剩余四项）

> 承接 `docs/阶段文档/全局复查修复方案-2026-10-01.md`，本轮关闭剩余 P2-02 / P2-04 / P2-06 / P2-09。其余 P1 与 P2-01/03/05/07/08 已在前几轮修复。

## P2-02 旧式灵根免费定根

- `SaveState` 增 `legacyRootPending: boolean`（新档 `false`）。
- `migrateSave`：旧档缺 `spiritRoots`（`schemaVersion < 14`）时 `legacyRootPending = true`，`spiritRoots = [validSpiritRoot(spiritRoot)]`，`resonance = null`；旧档已自定新灵根的（有 spiritRoots）不受影响。
- `setResonance`：`legacyRootPending` 时拒绝「需先完成定根」。
- 新增 `settleRoots(state, nowMs, roots)`：免费、不占洗髓机会、只提交一次；设置 `spiritRoots`、清 `legacyRootPending`、清 `resonance`，记修仙录。
- `createGame`/`normalizeSave`/`validateSpiritRoots` 相应补默认与校验。
- 人物页：`legacyRootPending` 时显示「旧式灵根（金），可免费定根一次」+ 灵根选择（五行多选/变异单选）+ 确认；完成后不再显示。

## P2-04 成长页面与引擎门槛一致

- `dongfu`：每座建筑显示下一级境界门槛、费用（含炼丹炉残页）与满级状态（按 `CONFIG.…levels.length`，不写死旧上限）；未达门槛禁用并说明。
- `beibao` 炼器：每个配方显示所需炼器台等级、境界、材料差额；未达禁用。
- `lilian` 秘境：奖励预览补对应分段灵材（`secretRealm` 成功额外 4 枚）。

## P2-06 资质影响与动作结果预览

- `xiulian` 功法下级成本按悟性折算显示（与 `upgradeTechnique` 实扣一致）。
- 洗髓选择补结果预览（经脉/悟性下一档效果、移除灵根后的灵根组合与共鸣影响）。
- 共鸣/侧重切换补前后对照（产速/攻击/减伤/成功率）。
- 重铸回执补新旧词条对照（已有 `recentLogs` 记录，页面展示）。
- `CreateCharacter` 补概率说明与功法费用示例。

## P2-09 存储故障反馈

- `game-context`：`apply`/初始化保存/重置加 try-catch，失败保留原进度并提示恢复路径，不冒充成功/新档；读档异常提示「读取失败，可重试或导出」，不静默当空档。

前端 `npm test` + typecheck/lint/build；浏览器独立来源走旧档定根、建筑/配方门槛展示、功法费用、存储异常注入。
