# v1.3 第三刀开发文档：分段灵材 + 过渡装备 + 佩饰 + 炼制

> 配套：`docs/PRD/PRD-修仙放置游戏-v1.3-二十境成长与洞府.md` 第四节。先文档、后开发。

## 1. 范围

- 新增 5 种分段灵材、8 件过渡装备（4 档剑衣）、7 件佩饰。
- 炼制配方接入灵材；每境地图首通/重复历练/对应秘境产出灵材。
- 淬炼本轮只做数据预留，流程后续接（见第 5 节）。

## 2. 数据模型

**灵材（新增 ResourceId，进 `resources`）**：

**过渡装备（新增 EquipmentId，slot weapon/armor）**：虚空刃/虚灵袍(炼虚2)、飞仙剑/飞升羽衣(真仙2)、大罗剑/三花道袍(大罗金仙2)、天命剑/因果道衣(天道圣人2)。属性与配方按 PRD 第四节表。

**佩饰（新增 EquipmentId，slot accessory）**：丹纹佩(金丹2)、护神佩(元婴4)、问道符(大乘4)、不朽印(金仙4)、归元环(混元大罗4)、太初印(大道圣人4)、鸿蒙印(鸿蒙10·首通获得)。

## 3. 掉落规则（实现口径）

- 每境 5 节点首通：各得所属段灵材 4 枚（在 `fightNode` 首通结算里按境界段补发）。
- 该段地图消耗每日三次重复奖励时，每次再得 1 枚（在重复奖励结算里补发）。
- 对应高阶秘境每日首次成功额外 4 枚（沿用秘境每日限次逻辑）。
- 灵材作为可选材料，不成为跨境突破硬门槛。

## 4. 涉及改动

1. `types.ts`：ResourceId/EquipmentId 扩展。
2. `config.ts`：`resources` 初始、装备表、crafts 配方（含灵材）、灵材分段映射。
3. `engine.ts`：`createGame` 资源初始化、`craftEquipment` 灵材校验与扣减、`fightNode` 首通/重复灵材掉落、`enterSecretRealm` 灵材奖励、迁移补灵材字段、坏档校验。
4. `labels.ts`/背包页：资源标签、新装备展示。

## 5. 本轮不做（后续）

- 淬炼流程（+5% 属性，费用=原配方 25% + 同档材料 2 枚）：只留配置占位。

- 新功法「首通本境首节点获得」领取流程（上刀遗留）。

## 6. 验收

- 新旧装备/佩饰配方成本、门槛与 PRD 一致；灵材不足不可炼。
- 灵材在消费前有稳定来源；首通/重复/秘境掉落与记录一致。
- 旧档迁移补灵材字段，不重发历史掉落；坏档拒绝。
- 前端测试 + typecheck/lint/build 通过。
