## 逐项说明

### P0-1 地图引入版本
- `engine.ts` 顶部加 `const MAP_YUNLING_INTRO_VERSION = 6;`。
- `validateMaps` 的 `allowMissing = isNewMap && schemaVersion < MAP_YUNLING_INTRO_VERSION`。
- 新增真实 `schemaVersion: 6` 且缺 `maps.map_yunling` 的坏档回归测试，断言 `ok: false`；`v6` 完整档迁移地图与结丹记录不变。

### P1-1 切换预览
- 引擎加 `buildSummary(state)` 返回 `{ cultivationPerSec, spiritPerSec, attack, reduction }`（产速来自 `productionBreakdown`、攻击来自 `playerStats`、减伤来自 `tribulationReductionInfo`）。
- `game-context` 的 `setTechnique`/`setAuxiliaryTechnique` 先构造切换后的临时状态，用 `buildSummary` 生成前后对比文案，`window.confirm` 展示后再提交。

### P1-2 修仙录
- `setTechnique`：若 `techniqueLevel[id]` 从 0 变 1，`pushMilestone(s, "technique", nowMs, 研习《名》)`。
- `upgradeTechnique`：每次 `pushMilestone(s, "technique", nowMs, 《名》精进至 N 重)`。
- `setAuxiliaryTechnique`：若 `auxiliaryTechnique` 原为 null，`pushMilestone(s, "technique", nowMs, 首次采用辅修《名》)`。

### P1-3 备份失败
- `game-context` 加载旧档：`backupSave` 失败时 `setNotice("存档备份失败，已保留原档，请刷新重试或先导出")`，`setReady(true)` 后 `return`，不执行 `migrateSave`/`persistSave`。

### P2-1 显示精度
- `labels.ts` 加 `fmtPct(x)`：`Math.round(x*1000)/10`，整数不带 `.0`。
- 修炼页 `eff`、渡劫/结丹预览的减伤改用 `fmtPct`。
- 洞府页藏经阁不足时：`还差灵石 X、残页 Y`。

## 验收标准
1. 前端 101 + 新增回归测试全绿；`tsc --noEmit` 与生产构建通过。
2. 浏览器：真实 v6 缺云岭地图坏档拒绝且现档不变；主辅切换确认框展示前后四项；修仙录记录研习/升级/首次辅修；备份失败提示（模拟）；减伤 2.5%/7.5% 精确显示；藏经阁差额具体。
3. 既有 v0.7/v0.8 修复不回退。
