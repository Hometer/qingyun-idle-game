# 阶段 3 · v1.2 子阶段 B/C 开发文档（内容补齐 + 金丹 + 元婴入境）

> 配套：`docs/PRD/PRD-修仙放置游戏-v1.2-二十境.md`、`docs/阶段文档/阶段3-前端/第3阶段v1.2开发设计.md`。
> 范围：补齐炼气/筑基中间层历练、金丹二至十层及历练、金丹十层→元婴入境试炼。**数值沿用插值骨架，后期统一校准**（产品经理 2026-09-27 决定）。

## 1. 内容补齐（炼气四~九层、筑基三~九层）

子阶段 A 已把旧「圆满」映射到新「十层」，但中间层（qi4~9、zhuji3~9）缺历练节点。本轮在既有地图插入新节点，不改动已迁移节点（厉鬼/鬼王 qi10、护丹灵 zhuji10 保持），旧档不降进度。

- 幽冥谷新增 3 节点：幽狼(qi5)、尸傀(qi7)、幽魂(qi9)，插在阴魂(qi3) 与 厉鬼(qi10) 之间。
- 云岭古道新增 3 节点：石傀王(zhuji4)、灵猿(zhuji6)、山魈王(zhuji8)，插在古道石傀(zhuji2) 与 护丹灵(zhuji10) 之间。
- 敌人/首通/重复收益按相邻已有节点线性插值，`suppressRate` 单调递增。

## 2. 金丹二至十层 + 金丹历练

- `config.realms` 增 jindan2~jindan10（成本/属性由 jindan1 与十层目标线性插值，圆满=jindan10）。
- 新增地图 `map_jindan`（金丹秘境），5 节点：丹房遗影(jindan2)、丹炉火灵(jindan4)、丹劫幻象(jindan6)、丹煞(jindan8)、元婴裂隙(jindan10)。
- 地图解锁：`realm >= jindan1` 解锁 `map_jindan` 首节点（仿 `syncYunlingUnlock`，新增 `syncJindanUnlock`）。
- 镇压位 `suppression`/`suppressionSince`/`maps` 增 `map_jindan`。

## 3. 金丹十层→元婴入境试炼

- `config.realms` 增 yuanying1（元婴一层，金丹十层后的下一境一层）。
- 新增试炼配置 `yuanyingTrial`（五波百分比 + 灵石成本），复用 `simulateTribulation`。
- 新增 `yuanyingTrialGateOk`/`previewYuanyingTrial`/`startYuanyingTrial`，入口条件：`realm === jindan10` 且首通 map_jindan 末节点（元婴裂隙）。
- 试炼成功晋入 `yuanying1`，失败境界不动、消耗照扣（沿用结丹试炼规则）。

## 4. 通用规则（沿用，不重造）

- 小进阶：1~9 层稳妥/冲关、失败保底 0~2；十层停止小进阶，满足条件手动跨境。
- 跨境：条件、消耗、预计结果、失败代价先展示，玩家确认后一次提交；成功进下一境一层，失败不降境。
- 存档：`SCHEMA_VERSION` 保持 10，无新增持久字段；`maps`/`suppression` 的 `map_jindan` 旧档迁移补默认（`migrateSave`/`normalizeSave`）。

## 5. 验收标准

- 炼气/筑基/金丹各十层可到达；九层不可跨境；十层满足条件可挑战；失败不降境；下一境从一层开始。
- 旧 v1~v9 档迁移后境界/资源/解锁不降；`map_jindan` 旧档补默认且坏档拒绝。
- 双标签同一突破/跨境只成功一次；刷新后结果一致。
- 未开放境界（元婴二层及以后）不出现可点按钮；元婴一层为当前最高开放境界。
- 桌面/360/390/430px 进度与试炼预览可读可操作。
- 前端测试 + typecheck/lint/build 通过；真实玩家/真机标「待验」。
