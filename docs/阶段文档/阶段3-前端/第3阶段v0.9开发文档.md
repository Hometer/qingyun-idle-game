# 阶段 3 · v0.9 开发文档

> 配套：`docs/PRD/PRD-修仙放置游戏-v0.9.md`（探索变化：三个秘境，主动进入 + 确定性战斗 + AI 进入叙事 + 每日限次）。
> 本版只做秘境；不做 v1.0 炼器、宗门/灵兽/道侣/轮回/账号；不新增概率战斗、随机词条、付费资源或在线系统。

## 1. 目标

- 新增三个秘境（灵药谷 / 古修遗迹 / 幽窟险境），按境界开放，每日各限一次。
- 秘境是主动进入的确定性回合战斗：胜发对应主题奖励、败无奖励；不掷概率。
- AI 只写进入叙事（复用现有际遇管线 + 模板降级），胜负与掉落由引擎决定。
- 修仙录/图鉴记录探索结果；旧地图/镇压/长期任务/每日目标不被替代。

## 2. 数据模型（schema v7 → v8）

`SCHEMA_VERSION` 7 → **8**。新增：

```ts
export type SecretRealmId = "realm_herb" | "realm_relic" | "realm_deep";

export interface SecretRealmLog {
  realm: SecretRealmId;
  won: boolean;
  reward: Resources; // 实际获得（败为全 0）
  at: number;
}

// SaveState 增：
secretRealmDate: string;              // "YYYY-MM-DD"，跨日重置
secretRealmUsed: Record<SecretRealmId, boolean>; // 当日是否已挑战
secretRealmLog: SecretRealmLog[];     // 探索记录（修仙录/图鉴回看）
```

- 跨日重置：`ensureSecretRealm(s, nowMs)` 在 `settle` 内随 `ensureDaily` 一起执行；日期变了就清空 `secretRealmUsed` 并更新 `secretRealmDate`。
- `migrateSave`/`normalizeSave` 对 v1～v7 旧档补默认：`secretRealmDate = 今日`、`secretRealmUsed` 全 false、`secretRealmLog = []`。

## 3. 引擎能力

- `predictSecretRealm(state, realmId)`：复用 `runBattle`，返回敌我属性与胜负预估。
- `enterSecretRealm(state, nowMs, realmId)`：`settle` → 校验境界门槛 → 校验当日未挑战 → 执行确定性战斗 → 胜则发奖励、败则无；标记 `secretRealmUsed`、写 `secretRealmLog`、`pushMilestone`（`秘境「名」成功/失败，得 …`）、`revision += 1`，单事务返回。
- 迁移与导入：校验 `secretRealmUsed` 布尔、`secretRealmLog` 结构、奖励非负、秘境 ID 合法；坏档拒绝并保留现档。

## 4. 规则基线（config）

```ts
secretRealms: {
  realm_herb:  { name: "灵药谷",   gate: "foundation1", enemy: { attack: 25, defense: 16, hp: 200 }, reward: { herb: 30, spiritStone: 100 } },
  realm_relic: { name: "古修遗迹", gate: "foundation2", enemy: { attack: 28, defense: 18, hp: 240 }, reward: { page: 8, spiritStone: 200 } },
  realm_deep:  { name: "幽窟险境", gate: "foundation3", enemy: { attack: 32, defense: 21, hp: 300 }, reward: { spiritStone: 500, herb: 50 } },
},
```

后端际遇模板新增三个进入叙事事件：`event_realm_herb / event_realm_relic / event_realm_deep`，各含 `title + body + 单一 option("进入")`；模板降级文案与引擎配置对齐。

## 5. UI

- 历练页「秘境」区块：三张秘境卡展示境界门槛、敌方属性、奖励、今日剩余次数与胜负预估；「进入秘境」按钮在未达境界或当日已挑战时禁用并说明。
- 进入流程：点「进入秘境」→ 拉取 AI 叙事（`generateEncounter`，单一「进入」选项）→ 弹层展示叙事（标题+正文）+「开始探索」→ 确认后执行 `enterSecretRealm` → 结果面板显示胜败与奖励（复用 v0.3 结果面板）。
- 人物页/修仙录与图鉴：回看秘境探索记录与首次成功。

## 6. 子阶段

1. **子阶段 A｜引擎**：schema v8 + 秘境配置/预估/进入 + 跨日重置 + 迁移/导入校验；引擎测试（门槛、每日限次、跨日重置、胜败奖励、坏档拒绝）。
2. **子阶段 B｜界面与叙事**：历练页秘境卡、进入叙事弹层、结果面板；后端三个进入叙事模板；360/390/430px 与深浅色复验。

## 7. 验收（对齐 PRD 第 6 节）

- 开放与门槛：未达境界不可进；每日一次、跨日重置。
- 确定性结算：预估与实战一致；胜得对应奖励、败无奖励；不重复领取。
- AI 叙事：进入时展示、模板降级可用；AI 不决定胜负掉落；刷新不重复调用。
- 记录与回看：修仙录/图鉴可回看；旧档不补造历史。
- 存档与并发：v1～v7 旧档无损升级；坏档拒绝现档不变；双标签同秘境同日只成功一次。
- 不破坏旧内容：旧地图/镇压/长期任务/每日目标/天气星象照常；秘境战斗不计入每日战斗目标。
- 界面：桌面与 360/390/430px、深浅色、减少动效可操作。
