# v1.4 子阶段 C 开发文档：洗髓

> 配套：`docs/PRD/PRD-修仙放置游戏-v1.4-灵根与修行资质.md` R60/R61。先文档、后开发。

## 1. 范围

- 筑基/化神/真仙/混元金仙/天道圣人各得一次洗髓机会，共五次；旧高境界存档按已达节点补齐（由境界推导，不另存）。
- 每次三选一：经脉提升一档 / 悟性提升一档 / 移除一种五行（非变异且 >1 系）。
- 费用按被使用的机会档；历史记录可回看；双标签只成功一次。

## 2. 数据模型

- SaveState 增 `marrowHistory: Array<{ type; from; to; cost; at }>`。
- 已用机会数 = `marrowHistory.length`；可用 = 已达境界档数 − 已用。
- 费用档：筑基 1000/50、化神 10000/200、真仙 100000/1000、混元金仙 500000/4000、天道圣人 2000000/10000（灵石/灵草）。

## 3. 规则

- 经脉/悟性不能越过最高档；单灵根不能移除；变异灵根不能用移除选项。
- 改变产速前先结算；在途任务/闭关不回算。
- 余额不足显示缺口不扣费；持久化失败不消耗机会。

## 4. 涉及改动

1. `types.ts`：`marrowHistory`。
2. `config.ts`：洗髓五档（境界 + 费用）。
3. `engine.ts`：`marrowChances`/`marrowCost`/`marrow`（三选一）、迁移补 `marrowHistory`、坏档校验。
4. `renwu/page.tsx`：洗髓入口、三选一预览、历史回看。

## 5. 验收

- 机会按境界获得、费用按档；三选一效果正确、不越档；旧档补机会一次不重发。
- 双标签只成功一次；余额不足不扣费；前端测试 + typecheck/lint/build 通过。
