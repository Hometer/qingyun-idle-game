# v1.3 第七刀开发文档：首通获得领取流程

> 配套：`docs/PRD/PRD-修仙放置游戏-v1.3-二十境成长与洞府.md` 第三、四节。先文档、后开发。

## 1. 范围

- 5 本新功法改为「首通本境首节点获得」：首通该境地图首节点后记入已获得，再按藏经阁等级 + 境界可研习。
- 鸿蒙印改为「终点守关首通获得」：首通鸿蒙地图末节点直接获得。

## 2. 数据模型

- SaveState 增 `learnedNewTechs: string[]`（已获得的新功法 ID，不重发）。
- 新功法门槛由「藏经阁+境界」增补「已首通获得」这一项。

## 3. 规则

- 首通授予只发生一次；旧档迁移：已达境界且已首通该节点的旧档补记 `learnedNewTechs`。
- 未首通时，功法列表显示「需首通本境首节点方可获得」。
- 鸿蒙印首通直接入包，不占炼制。

## 4. 涉及改动

1. `types.ts`：`learnedNewTechs: string[]`。
2. `engine.ts`：`NEW_TECH_REQUIREMENT` 加 `grantMap`；`fightNode` 首通判定授予新功法/鸿蒙印；`techniqueLockReason` 增「已获得」检查；迁移补 `learnedNewTechs`。
3. 人物/修炼页文案随门槛显示。

## 5. 验收

- 首通前不可研习新功法、显示原因；首通后可按藏经阁+境界研习，不重发。
- 鸿蒙印终点首通获得一次。
- 旧档迁移不重发、坏档拒绝；前端测试 + typecheck/lint/build 通过。
