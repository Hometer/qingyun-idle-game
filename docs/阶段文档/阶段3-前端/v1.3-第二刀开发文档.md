# v1.3 第二刀开发文档：新增 5 本境界功法 + 新功法效果类型

> 配套：`docs/PRD/PRD-修仙放置游戏-v1.3-二十境成长与洞府.md` 第三节。本刀为补记文档，实现已随提交 `5990b17` 完成。

## 1. 范围

- 新增 5 本境界功法（各 3 重，一重 50% / 二重 75% / 三重 100%）。
- 新效果类型：气血百分比、防御加成；修为/灵气/攻击/减伤接入既有公式。

## 2. 新功法（解锁境 · 主修满效）

| 功法 | 解锁 | 主修满效 |
| --- | --- | --- |
| 凝婴心经 | 元婴 | 气血 +12%、灵气 ×1.15 |
| 云海问道经 | 大乘 | 攻 +16、防 +8 |
| 不朽金身诀 | 金仙 | 气血 +20%、减伤 +8% |
| 混元归一诀 | 混元大罗 | 修为 ×1.45、灵气 ×1.25 |
| 太初道章 | 大道圣人 | 攻 +26、减伤 +8% |

辅修取增量一半；倍率按「超过 1 的部分」折算。

## 3. 关键改动

- `config.ts`：新增 5 本功法与三级效果。
- `types.ts`：`TechniqueId` 扩展 5 个 ID。
- `engine.ts`：`newTechEffect` 通用取值、`techniqueCultivationMult/SpiritMult/AttackBonus` 纳入新功法、新增 `techniqueDefenseBonus/techniqueHpMult`、`tribulationReductionInfo` 纳入减伤、`playerStats` 应用防御与气血百分比。
- 解锁门槛：藏经阁等级 + 境界（首通获得在第七刀补）。

## 4. 验收

- 新功法效果正确、主辅取值正确；未到门槛不可研习；前端测试 + typecheck/lint/build 通过。
