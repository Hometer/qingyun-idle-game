# v1.4 子阶段 B 开发文档：灵根共鸣

> 配套：`docs/PRD/PRD-修仙放置游戏-v1.4-灵根与修行资质.md` R58/R59。先文档、后开发。

## 1. 范围

- 五行共鸣（金木水火土）+ 三种变异共鸣（雷冰风），同一时刻只启用一项。
- 人物页手动切换（只可选灵根所含共鸣）。
- 共鸣效果接入战斗、产速、冲关、试炼、任务时长。

## 2. 数据模型

- SaveState 增 `resonance: string | null`（当前启用共鸣，未启用为 null）。
- 共鸣强度：单灵根 5%、双 4%、三 3%、四 2%、五 1%；变异按 5%。

## 3. 效果（config + 引擎单一来源）

| 共鸣 | 效果 | 生效范围 |
| --- | --- | --- |
| 金 | 对敌最终伤害 ×(1+强度) | 地图历练/每日秘境 |
| 木 | 灵草产速 ×(1+强度) | 已建灵田 |
| 水 | 灵气产速 ×(1+强度) | 普通修炼 |
| 火 | 修为产速 ×(1+强度) | 普通修炼 |
| 土 | 受到最终伤害 ×(1−强度) | 地图历练/每日秘境 |
| 雷 | 冲关成功率 +4 个百分点（≤100%） | 冲关进阶 |
| 冰 | 跨境试炼每波伤害 ×0.97 | 试炼 |
| 风 | 新开始任务耗时 ×0.96（向上取整分钟） | 持续历练/闭关 |

## 4. 涉及改动

1. `types.ts`：`resonance: string | null`。
2. `config.ts`：共鸣强度表 + 变异效果参数。
3. `engine.ts`：`availableResonances`/`resonanceStrength`/`setResonance`、金土木水火在 `runBattle`/`productionBreakdown` 接入、雷在冲关成功率、冰在试炼伤害、风在任务耗时。
4. `renwu/page.tsx`：共鸣选择与预览。
5. 迁移：旧档 `resonance = null`。

## 5. 验收

- 同一时刻只生效一种；可选共鸣属于灵根；切换前结算、刷新保持。
- 金/土战斗、木/水/火产速、雷冲关、冰试炼、风任务与预览一致；不追溯旧收益。
- 前端测试 + typecheck/lint/build 通过。
