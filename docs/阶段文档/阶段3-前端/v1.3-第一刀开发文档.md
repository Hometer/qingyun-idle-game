# v1.3 第一刀开发文档：基础功法续级 + 洞府建筑升级

> 配套：`docs/PRD/PRD-修仙放置游戏-v1.3-二十境成长与洞府.md` 第三、六节。本刀为补记文档，实现已随提交 `58a79bd` 完成。

## 1. 范围

- 四本基础功法 Lv3 → Lv12（按境界分段开放），Lv1~3 效果、费用、旧档等级不变。
- 六座洞府建筑分段开放新等级，终点有上限：修炼室/聚灵阵/灵田 Lv8、炼丹炉 Lv6、藏经阁 Lv7、炼器台 Lv6。

## 2. 数值（与 PRD 一致）

- 基础功法 Lv4~12 残页费：40/350/700/2000/4500/9500/19000/40000/80000。
- 青云诀/聚元诀每级 ×1.03（主辅同乘）；破岳诀每级攻 +2（辅 +1）；玄龟诀每级减伤 +1 个百分点（辅 +0.5）。
- 洞府新等级费用/倍率按 PRD 6.2~6.4 表。

## 3. 关键改动

- `config.ts`：buildings/techniques/library/forge 等级表扩展。
- `engine.ts`：`upgradeBuilding`/`buildLibrary`/`buildForge`/`upgradeTechnique` 上限改为按 `config.levels.length` 推导；校验函数同样泛化。
- 页面：洞府/修炼页硬编码上限改为按配置推导。

## 4. 验收

- 功法可升至 Lv12、建筑可升至本版上限；Lv1~3 原值与旧档不变；前端测试 + typecheck/lint/build 通过。
