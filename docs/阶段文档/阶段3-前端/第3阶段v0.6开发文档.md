# 阶段 3 · v0.6 开发文档

> 配套：`docs/PRD/PRD-修仙放置游戏-v0.6.md`（可选修行资质 + 稳妥/冲关两种小进阶，失败保底）。
> 本版只做「资质取向」与「概率小进阶」，不新增境界/地图/敌人/装备/账号/模型调用；炼气圆满→筑基仍沿用现有手动渡劫。

## 1. 目标

- 创建角色时可选三种修行资质（均衡 / 凝神 / 聚灵），系统随机推荐一项、玩家可改选；资质固定影响修为/灵气产速倍率，与五行灵根解耦。
- 炼气一层→二层、二层→三层、三层→圆满三次小进阶改为「稳妥 / 冲关」两种方式：稳妥 100% 成功（成本 ×1.15），冲关 80/90/100% 成功率（失败仅扣 20%，每层最多两次失败保底）。
- 资质、每层保底计数、进阶尝试记录随存档持久化（schema v4 → v5）；v1～v4 旧档自动升级为「均衡」资质、保底 0，原资源/境界不变。
- 概率判定在确定性引擎的单个事务里完成，随机源可注入用于测试；界面预览与实际引擎读同一套配置。

## 2. 数据模型（schema v4 → v5）

`SCHEMA_VERSION` 4 → **5**。`SaveState` 新增：

```ts
export type AptitudeId = "balanced" | "focus" | "spirit"; // 均衡 / 凝神 / 聚灵
export type BreakthroughLayer = "qi1" | "qi2" | "qi3";    // 三段小进阶对应的当前层
export type BreakthroughMethod = "steady" | "risky";       // 稳妥 / 冲关

export interface BreakthroughRecord {
  layer: BreakthroughLayer;   // 当次在那一层
  method: BreakthroughMethod;
  success: boolean;
  probability: number;        // 当次成功率（0.8 / 0.9 / 1.0）
  cost: Resources;            // 实际扣除的资源
  at: number;                 // epoch ms
}

// SaveState 新增：
aptitude: AptitudeId;
breakthroughFails: Record<BreakthroughLayer, number>; // 每层保底计数 0~2，跨层不继承
breakthroughRecords: BreakthroughRecord[];            // 结构化尝试记录（修仙录回看）
```

- `breakthroughFails` 只记冲关失败；成功进入下一层时该层计数归零。
- `migrateSave`/`normalizeSave` 对 v1～v4 旧档补默认值：`aptitude = "balanced"`、`breakthroughFails` 全 0、`breakthroughRecords = []`，其余字段保留不动。

## 3. 引擎能力

- 资质倍率辅助：`aptitudeCultivationMult(s)` / `aptitudeSpiritMult(s)`，读取 `CONFIG.aptitudes[s.aptitude]`。
- `settle`：修为产速 ×资质倍率、灵气产速 ×资质倍率；离线结算仍每次最多 12h，天气跨日/镇压复聚分段逻辑不变。
- `productionBreakdown`：产速明细追加资质倍率项（基础 × 资质 × 建筑 × 功法）。
- `createGame(name, spiritRoot, aptitude, nowMs)`：创建时写入资质。
- `breakthroughCosts(state, method)`：返回 `{ success: Resources; failure: Resources }`，供 UI 预览与引擎共用同一份计算。
  - 稳妥：`success = ceil(完整成本 × 1.15)`，`failure = 0`。
  - 冲关：`success = 完整成本`，`failure = ceil(完整成本 × 0.2)`。
  - 完整成本 = 下一层 `cultivationCost`/`spiritCost`（一层→二层 120/20，二层→三层 300/50，三层→圆满 700/100）。
- `breakthrough(state, nowMs, method = "steady", rng: () => number = Math.random)`：
  1. `settle` 后校验境界（qi1/qi2/qi3 才走概率小进阶；qi4 提示先渡劫；foundation1 提示已满级）。
  2. 校验资源 ≥ `breakthroughCosts(state, method).success`，不足则 `fail("修为/灵气不足")` 且不扣费。
  3. 冲关：`rate = min(0.8 + 0.1 × breakthroughFails[layer], 1)`；`rng() < rate` 判定成功。
     - 成功：扣完整成本、进下一层、该层 `breakthroughFails` 归零。
     - 失败：扣 20% 成本、该层 `breakthroughFails += 1`（封顶 2），境界不动。
  4. 稳妥：扣 1.15× 成本、进下一层、该层 `breakthroughFails` 归零（不先冲关也可稳妥）。
  5. 写入 `breakthroughRecords`（含 layer/method/success/probability/cost/at），并 `pushMilestone`（失败记录写明「哪一层、当次概率、实际消耗、下次概率」）、`revision += 1`。一次尝试的资源变动、境界、保底、记录、修订号作为同一事务返回。
- `importSave`：新增校验 `validateAptitude`（合法 ID）、`validateBreakthroughFails`（0～2 整数）、`validateBreakthroughRecords`（结构合法、cost 非负）、资源非负；坏字段拒绝导入并保留现档。
- `exportSave`：导出完整 v5 档，含资质/保底/尝试记录/在途长期任务快照。

## 4. 规则基线（config）

```ts
aptitudes: {
  balanced: { name: "均衡", cultivationMult: 1.00, spiritMult: 1.00 },
  focus:    { name: "凝神", cultivationMult: 1.05, spiritMult: 0.95 },
  spirit:   { name: "聚灵", cultivationMult: 0.95, spiritMult: 1.05 },
},
breakthrough: {
  riskyBaseRate: 0.8,     // 冲关初次成功率
  riskyFailBoost: 0.1,    // 每次失败 +10%
  steadyCostMult: 1.15,   // 稳妥成本倍率
  riskyFailCostMult: 0.2, // 冲关失败成本倍率
},
```

## 5. UI

- 创建页（`CreateCharacter`）：新增「修行资质」区块，显示三项资质名称与修为/灵气倍率，随机推荐一项并高亮；玩家可点选改选；加一句能懂的说明（如「凝神修炼更快但灵气稍慢，聚灵反之，均衡二者持平」）。五行灵根选择保持独立。
- 修炼页（`xiulian`）：三段小进阶处由单个「小进阶」改为「稳妥进阶」「冲关进阶」两个按钮，展示各自成本、冲关当前成功率与保底进度（如「已失败 1/2，成功率 90%」）；资源不足时禁用并显示缺口；点击后弹确认（冲关要说明失败只扣 20% 且不降境界），提交后结果面板分列境界变化、实际扣除、下次概率、下一步。
- 人物页（`renwu`）：显示资质名称与两项倍率；修仙录可回看进阶成功/失败记录（复用 `breakthroughRecords`/milestones）。
- 产速明细（`productionBreakdown`）：在「产速与来源」中体现资质倍率，且展示不高于实际到账。

## 6. 子阶段

1. **子阶段 A｜引擎**：schema v5 + 资质倍率接入 settle/生产明细/闭关快照 + `breakthrough` 概率化 + `breakthroughCosts` + v1～v4 迁移 + 导入/导出校验；引擎测试（注入固定 rng 覆盖初次成功、初次失败、二次失败、保底成功、稳妥必成、资源边界、跨层不继承）。
2. **子阶段 B｜界面**：创建页资质选择、修炼页两种进阶与确认/结果面板、人物页资质与修仙录展示；移动端宽度与深浅色复验。

## 7. 验收（对齐 PRD 第 5 节）

- 创建：五种灵根 × 三种资质都可组合；初始推荐可改选；同资质下五行不产生不同产速。
- 产速：三种资质修为/灵气产速与公式一致；升级建筑/换功法先结旧收益再乘新倍率；刷新与 12h 上限不重复结算。
- 进阶：三段均能选两种方式；稳妥始终成功；注入 rng 覆盖初次失败/二次失败/保底成功/初次成功，扣费、境界、保底、记录一致。
- 资源边界：刚好够完整成本可冲关；刚好够稳妥成本可稳妥；不足显示缺口且零扣费；失败仅扣 20% 且资源不为负。
- 存档与并发：结果提交后刷新不重抽；双标签只成功一次；坏 v5 档不覆盖现档；重置不复活。
- 旧档与在途任务：v1～v4 升级后资质为均衡、原资源/境界不变；v4 在途闭关按原快照领取。
- 首次筑基：三种资质分别从新档完成核心循环至筑基（稳妥路线可达），对照 v0.5 的 45～75 分钟基线记录差异，不把模拟冒充真实试玩。
