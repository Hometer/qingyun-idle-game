# v1.3 第四刀开发文档：丹药品阶 + 收益丹

> 配套：`docs/PRD/PRD-修仙放置游戏-v1.3-二十境成长与洞府.md` 第五节。先文档、后开发。

## 1. 范围

- 新增养元丹/聚灵丹（收益丹）四品阶（凡/灵/仙/道），服用一次性获得「当前产速 × 15/30/45/60 分钟」。
- 护劫丹三高品阶（灵 32% / 仙 34% / 道 36% 回血），凡品沿用 30%。
- 收益丹每日合计一枚；护劫丹手动预置、不占收益丹次数。
- 淬炼本轮只做数据预留（见第 5 节）。

## 2. 数据模型

**丹药 ID（进 inventory）**：

| 类型 | 品阶 | ID | 效果 |
| --- | --- | --- | --- |
| 养元丹 | 凡/灵/仙/道 | yangYuanDan_1..4 | 修为产速 × 15/30/45/60 分钟 |
| 聚灵丹 | 凡/灵/仙/道 | juLingDan_1..4 | 灵气产速 × 15/30/45/60 分钟 |
| 护劫丹 | 凡 | tribulationPill | 第三波回血 30%（现行） |
| 护劫丹 | 灵/仙/道 | tribulationPill_2..4 | 回血 32/34/36% |

**预置**：`preparedPill` 由布尔改为字符串（预置的护劫丹 ID），旧档布尔值迁移为「凡品或无」。

## 3. 规则

- 收益丹每日合计一枚，用 `daily.rewardedDan` 计数（零点重置）。
- 服用在点击时立即结算，不跨离线/重启；倍率基于当前产速。
- 护劫丹品阶不影响 40% 减伤上限，只改变第三波回血量。
- 高品阶配方需对应炼丹炉等级解锁。

## 4. 涉及改动

1. `types.ts`：`preparedPill: string | null`（原 boolean 迁移）、`daily` 加 `rewardedDan`、ItemId 扩展。
2. `config.ts`：`pills`（四品阶配方/效果/炼丹炉门槛）。
3. `engine.ts`：`craftPill` 泛化到品阶、`useGainPill`（收益丹服用+每日次数）、试炼回血读预置护劫丹品阶、迁移 `preparedPill`。
4. 背包页/洞府页：丹药展示与服用/预置。

## 5. 本轮不做

- 淬炼（+5% 属性，费用=原配方 25% + 同档材料 2 枚）：留配置占位，下刀做。
- 鸿蒙印「终点守关首通获得」领取流程。

## 6. 验收

- 四品阶丹药配方、效果、每日次数与 PRD 一致；护劫丹品阶只改回血、不改减伤上限。
- 收益丹点击即结算、每日一枚、零点重置；旧档迁移不重发。
- 前端测试 + typecheck/lint/build 通过。
