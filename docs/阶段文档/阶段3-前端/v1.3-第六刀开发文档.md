# v1.3 第六刀开发文档：背包页丹药与淬炼 UI

> 配套：`docs/PRD/PRD-修仙放置游戏-v1.3-二十境成长与洞府.md` 第四、五节。先文档、后开发。

## 1. 范围

把已就绪的引擎能力接到背包页界面：养元丹/聚灵丹炼制与服用、护劫丹品阶炼制与预置、装备淬炼。

## 2. 界面内容

- 炼丹区：养元丹/聚灵丹四品阶、护劫丹四品阶的配方展示、炼制按钮（按炼丹炉等级与材料可炼）。
- 服用区：收益丹服用（每日一枚、显示已服用状态）。
- 装备区：已拥有装备的淬炼按钮（一次、+5%、显示费用）。

## 3. 涉及改动

1. `game-context.tsx`：暴露 `craftGainPill`、`useGainPill`、`quenchEquipment`，`craftPill`/`togglePreparePill` 接品阶参数。
2. `beibao/page.tsx`：炼丹/服用/淬炼三块 UI。
3. `labels.ts`：丹药名称与品阶标签。

## 4. 验收

- 页面可炼制、服用、预置、淬炼，材料不足/每日一次/已淬炼等状态正确提示。
- 360/390/430px 无溢出；前端测试 + typecheck/lint/build 通过。
