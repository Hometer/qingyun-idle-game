## 逐项说明

### P1 按钮与实时资源不同步
- 根因：`game-context.tsx` 中 `view = settle(state, now)` 每秒随 `now` 更新；但 `jindanPreview` 只基于不变的 `state` 计算，导致 `canAfford`/`shortfall` 用旧余额。
- 修复：`jindanPreview` 改为基于 `view`（`view && view.realm === "foundation3"`）。五波战斗结果只依赖装备/境界，不随资源变化，每秒重算预览不会改变胜负预测。
- `startJindanTrial` 内部已在执行前 `settle` 并二次校验资源，保留该最终校验。
- 回归测试：`previewJindanTrial(settle(state, now))` 在修为从差 5 结算到跨过门槛后，`canAfford` 由 false 翻转为 true。

### P2 确认文案不准确
- 修复：`costTxt` 在 `pillPrepared` 时追加「、护劫丹 1 枚」；`failWarn` 改为「；本次预计失败，仍会消耗上述资源」（不再固定写「与预置丹药」）。
- 验收：未预置丹药时确认不提示丹药消耗；预置时提示。
