# 阶段 3 · v0.7 开发文档

> 配套：`docs/PRD/PRD-修仙放置游戏-v0.7.md`（筑基→金丹成长主线）。
> 本版只做「筑基一层→筑基二层→筑基圆满→金丹一层」主线 + 一张三节点地图 + 一次结丹试炼；不做 v0.8 功法/辅修、v0.9 秘境、v1.0 炼器，不新增账号/模型调用/云资源。

## 1. 目标

- 补一段筑基后的明确成长主线：两次筑基小进阶（沿用 v0.6 稳妥/冲关 + 失败保底），一次结丹试炼，晋入金丹一层（本版终点）。
- 新增地图「云岭古道」三节点，按「境界 + 首通前置」顺序解锁；沿用现有确定性回合战斗、镇压 24 小时复聚、持续历练、际遇机制。
- 境界提升战斗属性（攻/防/气血），但不额外乘产速；产速仍由资质、建筑、主修功法决定。
- 结丹试炼为确定性五波预览（22%/27%/32%/37%/42%），沿用减伤上限 40% 与护劫丹机制，额外消耗灵石 3000；结果独立记录，不覆盖首次天劫战报。

## 2. 数据模型（schema v5 → v6）

`SCHEMA_VERSION` 5 → **6**。新增：

```ts
// RealmId 增：foundation2(筑基二层) / foundation3(筑基圆满) / jindan1(金丹一层)
// MapId 增：map_yunling(云岭古道)
// BreakthroughLayer 增：foundation1 / foundation2

// SaveState 增：
jindanTrial: TribulationLog | null; // 结丹试炼独立记录（复用 TribulationLog 结构）
```

- `breakthroughFails` 仍为 `Record<BreakthroughLayer, number>`，扩展 layer 后需包含 `foundation1`、`foundation2` 两层（初始 0）。
- 境界战斗属性增量独立于装备：新增 `realmStatBonus(realm)`，返回 `{attack, defense, hp}`——foundation1 `+0/0/0`、foundation2 `+3/2/20`、foundation3 `+6/4/40`、jindan1 `+10/7/60`，qi1～qi4 与更早境界为 `0/0/0`。
- `migrateSave`/`normalizeSave` 对 v1～v5 旧档补默认：`jindanTrial = null`、新图层保底 0、新地图节点按境界解锁（已在筑基一层的旧档直接解锁云岭古道首节点，不要求先打旧图鬼王）。

## 3. 引擎能力

- `playerStats`：攻击/防御/气血 = 基础 + 装备 + `realmStatBonus(realm)`。
- `breakthrough`：扩展支持 `foundation1`、`foundation2` 两层（完整成本 3000/400、6000/800），沿用 v0.6 的 `breakthroughCosts`（稳妥 ×1.15 向上取整）与冲关 80/90/100% 保底；保底跨层不继承。
- 新地图：`MAP_ORDER` 增 `map_yunling`，三节点 `断崖山魈(gate foundation1)`、`古道石傀(foundation2)`、`护丹灵(foundation3)`；战斗/镇压/持续历练/际遇沿用现有逻辑，首通只发修为+灵石、重复只发修为。
- `previewJindanTrial(state)` / `startJindanTrial(state, nowMs)`：解锁校验（筑基圆满 + 护丹灵已首通 + 修为 12000 + 灵气 1600 + 灵石 3000）；五波 22/27/32/37/42% ×(1-减伤)，护劫丹第三波后回 30%；成功晋 jindan1、失败不降境界，结果落 `jindanTrial`。
- 迁移与导入：新增字段校验（境界、地图节点、`jindanTrial` 结构、筑基层保底 0~2、负资源拒绝）。

## 5. UI

- 修炼页：筑基一层/二层显示下一境界、两种进阶方式与属性变化；筑基圆满显示结丹试炼准备与逐波预览；金丹一层显示「本版主线已达成」。
- 历练页：新增「云岭古道」地图卡片，三节点显示境界条件、敌人、首通/重复奖励、镇压产速；未达境界或未首通前置显示具体原因；持续历练仅列已首通节点。
- 人物页/修仙录：回看两次筑基进阶成功/失败、云岭古道首通、结丹试炼五波结果与金丹达成时间。

## 7. 验收（对齐 PRD 第 6 节）

- v0.6 旧档续玩：炼气旧档规则不变；筑基一层旧档无损升级，能看到下一目标与云岭古道首节点；在途任务按原快照领取。
- 两次筑基进阶：两层稳妥必成与冲关 80/90/100% 保底；资源刚好够可提交、不足零扣费；失败不掉境界；跨层保底不继承。
- 三节点路线：筑基一层现有装备可首通首节点，进阶后依次解锁后两节点；预测与实际一致；首通只发一次。
- 新图镇压与长期任务：第三地图 24 小时独立复聚、分段结算；只有已首通节点可安排持续历练；刷新/关闭重开/导入后快照不变。
- 结丹试炼：未达条件不可挑战；五波预览与实战一致；成功金丹一层且只扣费一次；失败不降境界；原天劫战报仍可回看。
- 并发、坏档与终点：双标签并发不双扣/双领；坏 v6 档不覆盖现档；金丹一层显示本版终点。
