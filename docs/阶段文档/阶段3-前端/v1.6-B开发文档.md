# v1.6 阶段 B 开发文档：重铸 + 封存

> 配套：`docs/阶段文档/规划/v1.6-装备功法丹药词条设计汇总-待确认.md` 第二节第 5 点。阶段 A（词条池 + 生成 + 展示）已随 `dd338aa` 完成。先文档、后开发。

## 1. 范围

- 重铸：重新随机该装备的词条，展示新旧结果与费用，玩家确认后提交。
- 封存：最多锁定 1 条词条，锁定后重铸费用提高；可解锁。
- 只消耗现有灵石、玄铁（后续可加对应分段灵材），不新增货币。

## 2. 数据模型

- SaveState 增 `lockedAffixes: Record<string, string>`（装备基础 ID → 锁定的词条 ID，每件最多 1 条）。

## 3. 规则

- 重铸费用：基础灵石 + 玄铁；有锁定词条时费用 ×1.5。
- 重铸时锁定词条保留，其余重新随机；确定性种子保证预览与提交一致。
- 锁定/解锁也收一次费用（灵石 + 玄铁）；不销毁装备。

## 4. 涉及改动

1. `types.ts`：`lockedAffixes`。
2. `config.ts`：重铸/锁定费用。
3. `engine.ts`：`reforgeCost`/`previewReforge`/`reforgeEquipment`/`lockAffix`/`unlockAffix`、随机生成时跳过锁定词条、迁移补 `lockedAffixes`、坏档校验。
4. `beibao`：重铸/锁定/解锁入口 + 新旧词条预览。

## 5. 验收

- 重铸后锁定词条保留、其余变化；费用正确；锁定后费用提高；解锁后恢复。
- 预览与提交一致；双标签只成功一次；坏档拒绝。
- 前端测试 + typecheck/lint/build 通过。
