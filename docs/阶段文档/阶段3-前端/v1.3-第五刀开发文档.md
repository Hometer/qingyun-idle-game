# v1.3 第五刀开发文档：护劫丹高品阶 + 装备淬炼

> 配套：`docs/PRD/PRD-修仙放置游戏-v1.3-二十境成长与洞府.md` 第四、五节。先文档、后开发。

## 1. 范围

- 护劫丹三高品阶（灵 32% / 仙 34% / 道 36% 回血），凡品 30% 沿用。
- 装备淬炼一次（+5% 攻/防/气血），费用=原配方灵石/玄铁 25%（向上取整）+ 同档灵材 2 枚。

## 2. 数据模型

**护劫丹**：inventory 增 `tribulationPill_2/3/4`；SaveState 增 `preparedPillTier`（1~4，默认 1）。`preparedPill` 布尔保留（是否预置），品阶由 `preparedPillTier` 决定。

**淬炼**：SaveState 增 `quenched: string[]`（已淬炼装备 ID 列表，每件最多一次）。

## 3. 规则

- 试炼第三波回血读 `preparedPillTier` 对应 30/32/34/36%，不改 40% 减伤上限。
- 预置高品阶需先有对应库存；手动选择品阶。
- 淬炼不销毁装备；属性在 `playerStats` 里对已淬炼装备 ×1.05（向下取整）。
- 淬炼费用按该装备原配方（玄铁、灵石各 25% 向上取整）+ 所属段灵材 2 枚。

## 4. 涉及改动

1. `types.ts`：`preparedPillTier`、`quenched`。
2. `config.ts`：护劫丹高品阶配方；淬炼灵材映射（按装备所属段）。
3. `engine.ts`：`simulateTribulation` 回血按品阶、`startCrossStageTrial`/旧试炼按品阶扣丹、`togglePreparePill` 选品阶、`craftPill` 炼制高品阶、`quenchEquipment` + `playerStats` 淬炼加成、迁移。
4. 背包页：丹药品阶展示/预置/淬炼入口。

## 5. 本轮不做

- 淬炼的「下一境才可淬上一档」逐境节奏门槛（本轮做成可淬炼即淬，节奏后续按模拟调）。
- 「首通获得」领取流程（新功法 + 鸿蒙印）。

## 6. 验收

- 护劫丹品阶只改回血、不改减伤上限；预置/扣丹按所选品阶。
- 淬炼一次 +5% 属性、费用正确、不销毁；坏档拒绝。
- 前端测试 + typecheck/lint/build 通过。
