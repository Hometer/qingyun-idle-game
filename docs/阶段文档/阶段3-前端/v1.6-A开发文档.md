# v1.6 阶段 A 开发文档：装备独立实例 + 随机多词条

> 配套：`docs/阶段文档/规划/v1.6-装备功法丹药词条设计汇总-待确认.md`。产品经理已确认：分两阶段、词条 1~4 条随机、特殊词条本版本要做。

## 1. 范围

- 装备从「ID→数量」改为「独立实例」，同名装备可带不同词条。
- 每件装备随机 1~4 条词条；词条池含基础 7 类 + 特殊 5 类。
- 装备详情与换装对比；功法/丹药多效果展示同步。
- 特殊词条本版本做：暴击、突破率、每回合回血、低血触发、战斗所得修为。

## 2. 词条池（config 单一来源）

**基础词条**：攻击、防御、气血、战斗伤害（伤害 ×）、受伤减免（受击 ×）、修为产速、灵气产速。

**特殊词条**（本版本新增战斗规则）：

| 词条 | 效果 | 结算位置 |
| --- | --- | --- |
| 暴击率 | 攻击有 X% 概率伤害 ×1.5 | `runBattle` |
| 突破率 | 冲关进阶成功率 +X 个百分点 | `breakthroughSuccessRate` |
| 每回合回血 | 每回合开始时恢复 X 气血 | `runBattle` |
| 低血增伤 | 气血低于 30% 时造成伤害 +X% | `runBattle` |
| 战斗所得修为 | 战斗胜利额外获得 X 修为 | `fightNode` |

**数值范围（首轮，待模拟）**：攻击 +2~+10、防御 +1~+5、气血 +10~+50、伤害/产速 +2%~+8%、受伤减免 −2%~−8%、暴击 +2%~+10%、突破率 +1%~+5%、回血 +2~+10、低血增伤 +5%~+15%、战斗修为 +10~+50。

## 3. 数据模型

- `inventory` 改 `Record<string, number>`（实例 ID → 数量，本版一实例一件）。
- 新增 `itemInstances: Record<string, { baseId: string; affixes: Array<{ id: string; value: number }> }>`。
- `equipment`/`quenched` 改为引用实例 ID。
- schema v15 → v16。

## 4. 涉及改动

1. `config.ts`：词条池（12 类 + 数值范围 + 品质权重）。
2. `types.ts`：`itemInstances`、`inventory` 语义、`equipment`/`quenched` 改实例 ID。
3. `engine.ts`：随机词条生成、装备实例化、基础/特殊词条效果接入 `runBattle`/`breakthroughSuccessRate`/`fightNode`、旧档迁移（每件旧装备迁成保留原属性的旧版实例）、坏档校验。
4. `beibao`/`renwu`：装备详情（品阶/基础/词条/来源/换装对比/产速变化）。

## 5. 阶段 B（后续）

- 重铸（展示费用与新旧结果，玩家选保留哪组）。
- 封存（最多锁 1 条，锁定后重铸费用提高）。

## 6. 验收

- 每件装备随机 1~4 条，基础属性稳定；同名装备词条可不同。
- 特殊词条（暴击/突破率/回血/低血/战斗修为）结算正确、有战报展示。
- 守关/跨境不要求稀有词条；普通装备可通关。
- 旧档迁移每件旧装备成旧版实例、穿戴/淬炼对应正确；坏档拒绝。
- 前端测试 + typecheck/lint/build 通过。
