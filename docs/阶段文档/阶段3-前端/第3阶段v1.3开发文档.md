## 2. 经济模拟（先模拟，已跑）

存档脚本 `docs/阶段文档/阶段3-前端/v1.3-经济模拟.py`（可复现）。修为主线理想口径（不含材料瓶颈、建筑/功法即时满级）：

| 资质 | 登录 | 到鸿蒙道祖十层 |
| --- | --- | --- |
| 均衡 | 2 次/天 | 17 天 |
| 均衡 | 1 次/天 | 31 天 |
| 凝神 | 1 次/天 | 29 天 |
| 聚灵 | 1 次/天 | 32 天 |

**结论**：理想修为主线 17~32 天，快于 42~56 天目标。真实玩家会被**材料瓶颈**（灵石/残页/灵材供给、装备炼制、洞府/功法升级成本）和**非满额在线**拖慢，最终落在 42~56 天的区间内。若实测仍偏快，校准杠杆是 `config.realmProduction.growthPerStage`（现 ×1.22，可降至 ×1.15）或上调境界成本。**本轮不阻塞，先按 PRD 数值落地，逐境验证时再精调。**

## 3. 实现顺序

1. **config.ts**（唯一来源）：功法 Lv4~12、5 本新功法、4 档过渡装备 + 6 佩饰、养元/聚灵丹 + 护劫丹高品阶、5 种分段灵材、六座洞府新等级、淬炼规则、每境材料掉落。
2. **types.ts / engine.ts**：功法等级上限 12、新功法 ID 与效果、装备/佩饰/丹药/灵材/淬炼/洞府上限的引擎逻辑、存档迁移（schema v14）、导入校验、双标签提交。
3. **界面**：洞府六建筑新等级、藏经阁/炼器台新配方、背包丹药与淬炼、产速展示。
4. **测试 + 逐境验证 + 证据包**。

## 4. 验收（对齐 PRD 第十节）

- 逐境可玩：新建角色走通 20 境，功法/装备/丹药/材料/建筑按门槛出现，未到门槛仅预览。
- 建筑数值：六建筑升到本版上限，页面与引擎一致；境界不足/费用不足/满级均不扣资源。
- 资源闭环：五种灵材消费前有稳定来源；旧档已首通节点只补一次，不重发。
- 时长：可复现逐日模拟 42~56 天，至少一条无需氪金/无限刷图路线可达；偏离则给调整表。
- 可靠性：v1~v13 旧档迁移保留境界/首通/资源/建筑/装备/功法；坏档拒绝；双标签只成功一次。
- 交付：运行地址/复现步骤、360/390/430px 截图、自动化通过数、typecheck/lint/build、经济模拟、存档迁移样例、闸门表；真人试玩/真机未做标「待验」。
