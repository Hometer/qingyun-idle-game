# v1.4 验证报告（资质/共鸣/洗髓）

> 2026-09-27。方法：基于真实引擎回归测试（`balance.test.ts`，从元婴、12 小时/日）在平通经脉下给出 42~56 天，经脉是产速常数倍率，通关时长反比缩放。

## 一、战斗与试炼可达性

- 经脉（0.94~1.06）与悟性（0.94~1.06）**不参与战斗属性**，只影响产速与功法费用。
- 共鸣金（对敌伤害 +1%~5%）、土（受击伤害 −1%~5%）只会让战斗更轻松。
- 结论：此前 105 节点 0 死档、19 跨境试炼全可渡的结论**不变**；低资质（闭塞+迟钝）不锁境界/功法/地图，稳妥路线可通关。

## 二、经脉对通关时长的影响（目标 42~56 天）

| 经脉档 | 产速 | 通关时长 |
| --- | --- | --- |
| 闭塞 | ×0.94 | 45 ~ 60 天 |
| 滞涩 | ×0.97 | 43 ~ 58 天 |
| 平通 | ×1.00 | 42 ~ 56 天 |
| 通达 | ×1.03 | 41 ~ 54 天 |
| 天成 | ×1.06 | 40 ~ 53 天 |

- 极端组合（最慢闭塞 vs 最快天成）时长差约 **12.8%**，低于 PRD 设定的 20% 上限。✓

## 三、悟性影响

- 悟性只影响功法残页费用（迟钝 ×1.06 ~ 通明 ×0.94），不影响主线可达性与通关时长。✓

## 四、洗髓

- 五次机会（筑基/化神/真仙/混元金仙/天道圣人），三选一可把低资质逐步提升；低根可四次从五灵根精炼到单灵根。
- 旧高境界存档按已达节点补齐机会，不重发；双标签只成功一次。

## 五、结论

- 战斗/试炼无死档，低资质可通关。
- 经脉/悟性造成的时长差 ≤20%，符合 PRD 数值约束。
- 洗髓机制提供后天改善，低资质不成为永久劣势。

## 六、局限（如实）

- 通关时长是「平通=42~56 天」的反比估算，未单独跑全资源逐日模拟；精确落点仍需真人试玩校准。
- 悟性对"残页瓶颈"的实际影响（哪些功法早/晚满级）未做逐日材料模拟。
- 共鸣的实战收益（金/土对战斗节奏、雷冰风对成长）未做精细化收益对比，仅确认不破坏可达性。
