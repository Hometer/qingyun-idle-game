# v1.2 数值验证报告

> 2026-09-27。对象：二十境×十层的境界成本、属性、地图敌人、跨境试炼。方法：程序模拟 + 可达性校验。

## 一、可达性验证（战斗 / 试炼 / 秘境）

模拟全流程（炼气一层 → 鸿蒙道祖十层），每节点按「当前境界属性 + 已收集最佳装备 + 破岳诀 Lv3 攻+12」出战：

| 项 | 结果 |
| --- | --- |
| 105 个历练节点逐节点首通 | **0 个不可首通** |
| 19 个跨境试炼（满减伤 25% + 护劫丹） | **全部可渡**，剩余气血约 9%~17%（余量舒适，非临界） |
| 3 个秘境（灵药谷/古修遗迹/幽窟险境） | **全部可胜** |

结论：战斗与试炼无死档；三资质（均衡/凝神/聚灵）不参与战斗属性，稳妥/冲关不改变战斗，故上述结论对三种资质与两种路线均成立。

## 二、经济（成本 vs 产率）修正

- 初版生成用「每境成本 ×3」增长，累计到鸿蒙道祖一层约 **9.7 万亿修为**，按当前最高产率约 4.2 修为/秒需约 7 万年，明显失衡。
- 修正为「每境成本 ×1.3」增长（境界内仍十层线性到 2 倍），累计到鸿蒙道祖一层约 **9840 万修为 ≈ 271 天（约 9 个月）**，符合放置游戏量级。
- 敌人强度/属性/试炼波次与成本解耦，本次只改成本曲线，战斗与试炼可达性不受影响（已验证 154/154 测试通过）。

## 三、仍为「骨架待校准」的部分

1. 精确的目标时长（9 个月是粗估值，未含离线收益上限、镇压/秘境额外来源），产品经理可给定目标通关时长再精调增长系数。
2. 新秘境地图节点名仍是占位（秘境灵兽1~5），内容打磨时再换主题名。
3. 成本曲线为单一几何增长，未做「每境差异化节奏」（如某境故意卡点）。
