## 关键设计：装备独立实例（P0-1）

- `itemInstances: Record<string, { baseId: string; affixes: Affix[] }>`，实例 ID 用 `randomId()`。
- `inventory` 改为「实例 ID → 数量」（一实例一件）；`equipment` 三槽、`quenched`、`lockedAffixes` 均引用实例 ID。
- 获得装备（炼制/首通掉落）时创建实例并生成词条；重铸/锁定只作用于该实例。
- 旧档迁移：旧 `inventory`（baseId→count）逐个展开成实例（空词条或生成词条），旧 `equipment`/`quenched` 映射到对应实例，保留数量与穿戴状态。
- 兼容助手 `baseIdOf(state, id)`：实例 ID 取 baseId，旧 baseId 直通。

## 验收

- 两件同名装备各带独立词条，重铸一件不改另一件；旧档迁移保留数量与穿戴。
- 坏词条档拒绝且现档不变；schema v16；词条条数按境界限额。
- 地图/秘境战斗结算暴击/回血/低血/战斗伤害，预览与实战一致；战斗修为受每日上限。
- 重铸展示费用与新旧词条；装备详情完整。
- 前端测试（含 v1.6 专项）+ typecheck/lint/build 通过。
