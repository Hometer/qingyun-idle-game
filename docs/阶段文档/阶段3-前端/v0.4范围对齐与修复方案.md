# v0.4 范围对齐与修复方案

> 依据：`docs/evidence/阶段3-v0.4复验/验收复核.md`（V04-01～V04-08）与状态台账 D10 记录的 v0.4 待审阅稿范围。
> 结论：先按待审阅稿对齐范围，再修 P0/P1/P2，补测试与证据包。

## 1. 范围对齐（以待审阅稿为准）

上一版实现偏离了待审阅稿，需改回：

| 项 | 待审阅稿（本次对齐目标） | 上一版实现（要改掉） |
| --- | --- | --- |
| 每日目标 | 两项固定、完成后**手动领取** | 三项按日期抽取、自动发奖 |
| 天气/星象 | 天气、星象**两个独立**，各**一次限次**加成 | 单个持续生效的"天时" |
| 镇压复聚 | 每图独立，**24 小时** | 12 小时 |

### 1.1 每日目标（R18，两项固定、手动领取）
- 每天固定两项：
  1. 「完成 3 次战斗」→ 奖励残页 +3
  2. 「镇压 1 个节点」→ 奖励灵石 +40
- 进度随操作累计；达标后标记"可领取"，玩家手动点「领取」发放；不自动发。
- 跨天重置，未领取的跨天作废（不补发）；不按角色阶段过滤这两项（战斗与镇压对满级角色仍可执行）。

### 1.2 天气与星象（R19，两个独立、各一次限次）
- **天气**（每日一换，作用于"领取收益"，一次限次）：
  - 灵雨：今日首次领取收益，额外灵草 +30
  - 晴明：今日首次领取收益，额外修为 +100
  - 灵脉涌：今日首次领取收益，额外灵石 +80
  - 平常：无
- **星象**（每日一换，作用于"战斗"，一次限次）：
  - 吉星：今日首次战斗胜利，额外修为 +50
  - 破军：今日首次战斗，伤害按**最终伤害** +20%（一次）
  - 平常：无
- 限次用满即失效；跨天重置；两者互不影响。

### 1.3 镇压复聚（R20，每图 24 小时）
- 每张地图独立：镇压持续 24 小时，到期该图复聚；两张图互不影响。

## 5. 数据模型（schema v3 调整）

- `daily` 改为：`{ date, weather: {id, used}, astrology: {id, used}, goals: {battle: {progress, claimed}, suppress: {progress, claimed}} }`。

## 6. 验收

1. 天气/星象限次加成进入实际结算，展示、待领取、存档同源；跨天按日期分段。
2. 镇压 24h 到期前收益不丢，到期后归零；两图独立；迁移旧档不复聚不"剩 0 时"。
3. v1/v2/v3 档都能导入；坏 v3 档拒绝且不崩。
4. 两项目标手动领取、跨天作废；天气/星象各一次限次。
5. 杀伐/破军伤害按最终伤害 +20%，预览一致。
6. 新增测试覆盖上表数字与旧档样本；tsc/引擎/后端/构建全绿；浏览器重跑 + 证据包。
