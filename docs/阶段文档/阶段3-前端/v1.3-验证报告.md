# v1.3 验证报告（逐境 + 经济）

> 2026-09-27。方法：程序模拟（战斗/试炼逐节点、逐日经济）。

## 一、战斗与试炼可达性（逐境）

用 v1.3 新增的过渡装备、佩饰、功法（破岳诀 Lv12、云海问道经、太初道章、不朽金身诀、凝婴心经）与护劫丹道品模拟全流程：

| 项 | 结果 |
| --- | --- |
| 105 个历练节点逐节点首通 | **0 个不可首通** |
| 19 个跨境试炼（满减伤 40% + 道品护劫丹 36% 回血） | **全部可渡** |

结论：战斗与试炼无死档，三种资质/两种路线均成立（资质不参与战斗属性）。

## 二、经济逐日模拟（目标 42~56 天）

理想条件（每日满额收益 + 即时升级建筑/功法 + 每日养元丹）：

| 资质 | 登录 | 到鸿蒙道祖十层 |
| --- | --- | --- |
| 均衡 | 1 次/天 | 27 天 |
| 均衡 | 2 次/天 | 16 天 |
| 凝神 | 1 次/天 | 26 天 |
| 聚灵 | 1 次/天 | 28 天 |

**结论**：理想修为主线 16~28 天，**快于** 42~56 天目标。但理想模型未计入三处真实减速：

1. **残页瓶颈**：四本功法 Lv4~12 共需约 62 万残页，5 本新功法又约 15 万，装备/洞府另计——首通 + 每日三次重复 + 秘境的残页供给是主要瓶颈。
2. **灵石瓶颈**：洞府 Lv4~8、藏经阁、炼器台升级的灵石需求随境递增。
3. **非满额在线/非最优操作**：普通玩家不会天天满额、即时升级。

这三处会显著拖慢真实玩家，预计落到 42~56 天区间；但**精确值需完整材料模型模拟 + 真人试玩校准**，本轮理想模型不足以单独证明。

## 三、调整杠杆（若实测偏离）

- 偏快：`config.realmProduction.growthPerStage` 从 ×1.22 降到 ×1.15；或上调境界成本。
- 偏慢：反向调高 growthPerStage 或加残页/灵石供给。
