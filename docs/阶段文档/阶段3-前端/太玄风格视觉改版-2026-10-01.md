# 阶段 3 前端视觉改版记录（2026-10-01）

## 目标与依据

产品经理希望现有前端进一步贴近《太玄问道》的视觉氛围。参考其夜色背景、细金线、卷轴式面板和地图节点表达，保留《青云修仙录》的文字、原创云海素材与现有玩法。此任务是视觉与地图入口调整，不改变战斗、奖励、存档结构或 AI 接口。

## 页面与组件

- 全站：新用户默认深色；已有用户明确选择的浅色、深色、跟随系统偏好继续生效。背景、卡片、输入、按钮、导航统一为深蓝黑与暖金色，增加桌面篇章顶栏。
- 创建角色：保留原有建角字段与随机/自设流程，改为夜色封面与深色表单。
- 五主入口：收紧侧栏、角色资源栏和章节标题的间距，手机沿用底部导航。
- 历练：当前地图增加主线节点路线，标出可入、未启、已通；可入节点点击后打开原有详情，原有主线和支线列表、战斗入口、秘境入口保留。小屏幕节点过多时路线区域可横向滚动。

## 适配与风险

- 沿用 Next.js 15、现有 CSS 与组件，不增加依赖或外部图片。参考项目的代码、插画和商标未复制。
- 存档仍在 IndexedDB，主题仍在本地偏好；本轮没有数据迁移。
- 深色为新用户默认值，旧用户主动保存的浅色或跟随系统设置保持原值。浏览器禁用本地存储时以深色显示。
- 地图节点按钮仅改变详情选中状态；实际战斗仍走原有确定性引擎和确认流程。

## 验证

- 前端 202/202、后端 22/22 测试通过；TypeScript、Lint、生产构建通过。Lint 有两条既有警告，分别是引擎未用变量和 Context Hook 依赖。
- 生产服务在 5181 端口可打开。已有角色「林青」从开发服务切换到生产服务后仍恢复。
- 浏览器检查 390、768、1280、1440px；无页面横向溢出。深浅主题切换、五主入口、主线节点详情已检查。
- 真机触控体验与本轮视觉偏好由产品经理验收。v1.7 新增际遇的真实模型冒烟仍待单独完成。
