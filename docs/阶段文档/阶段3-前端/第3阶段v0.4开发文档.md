# 阶段 3 · v0.4 开发文档

> 配套：`docs/PRD/PRD-修仙放置游戏-v0.4.md`。三项新规则：每日任务、天气星象、镇压复聚。

## 1. 目标

给回访一个理由（每日任务）、给每天一点变化（天气星象）、给历练一个循环（镇压复聚）。全部确定性、可配置、不强制、AI 不参与。

## 2. 数据层（schema v3）

- `SCHEMA_VERSION` 2 → **3**。
- `SaveState` 新增：
  - `daily: { date: string; weather: string; quests: { id: string; done: boolean }[]; counters: { settle: number; battle: number; craft: number; suppress: number; breakthrough: number; encounter: number } }`
  - `suppressionSince: Record<MapId, number>`（各图镇压起始时间戳）
- `migrateSave` 兼容 v1/v2 → v3：补 `daily`（按当天生成）、`suppressionSince`（当前镇压节点按"已到期"或"从今起算"处理），其余保留。
- 每日任务、复聚随操作持久化；天气由日期派生、存入 `daily.weather` 供确定性计算。

## 3. 引擎新能力

### 每日任务
- `rollDailyQuests(dateStr)`：由日期哈希确定性取 3 个任务（池 6 选 3）。
- `ensureDaily(s, nowMs)`：跨天重置 `daily`（新任务 + 计数清零 + 刷新 weather）。
- `recordDailyEvent(s, nowMs, event)`：递增对应计数；对"已达标且未发奖"的任务标记 done 并发放固定奖励 + 写修仙录里程碑。
- 各引擎动作调用 `recordDailyEvent`：战斗→battle、炼丹→craft、镇压→suppress、进阶→breakthrough、际遇→encounter；"领取收益"由上下文调用引擎暴露的 settle 事件记录。

### 天气星象
- `weatherOfDate(dateStr)`：日期哈希 → 5 种天时之一（晴明 +15% 修炼、灵雨 +50% 灵草、灵脉涌 +30% 灵石、杀伐 +10% 战斗伤害、平常无）。
- `productionBreakdown` 与 `predictFight`/`fightNode` 读取 `state.daily.weather` 应用倍率，预览与实际同源；渡劫/进阶/际遇奖励不受影响。

### 镇压复聚
- `setSuppression` 写入 `suppressionSince[mid] = nowMs`。
- `settle` 内 `applySuppressionExpiry(s, nowMs)`：超过 `CONFIG.suppressionDurationHours`（12h）的镇压清除并记录提示；节点回到"已通关未镇压"。
- 节点详情/历练页显示镇压剩余时间。

## 4. UI

- 页头显示当天天气加成；人物页（或独立入口）显示每日任务与进度、可回看当日结果。
- 历练节点详情显示镇压剩余时间；复聚节点可再战再镇压。
- 每日任务完成时走结果面板回执（复用 v0.3 回执链路）。

## 5. 子阶段

1. **子阶段 A｜引擎**：schema v3 + 每日任务 + 天气 + 复聚，引擎测试。
2. **子阶段 B｜界面**：天气展示、每日任务入口、镇压剩余时间。

## 6. 验收

按 v0.4 PRD 第 4 节场景；新增测试覆盖：跨天任务重置、任务完成发奖不重复、天气倍率作用于产出与战斗且预览一致、镇压到期失效与再镇压、v2 档迁移。
