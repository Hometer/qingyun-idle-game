# 阶段 3 · v0.8 开发文档

> 配套：`docs/PRD/PRD-修仙放置游戏-v0.8.md`（修行取向：两级藏经阁 + 破岳诀/聚元诀 + 一个辅修位）。
> 本版只做「功法取向」；不做多存档位、宗门/灵兽/道侣/轮回/账号，不做 v0.9 秘境、v1.0 炼器；不新增模型调用/云资源。

## 1. 目标

- 新增「藏经阁」两级建筑：一级解锁破岳诀/聚元诀，二级开放一个辅修位。
- 四本功法（青云诀/玄龟诀/破岳诀/聚元诀）都支持主修与辅修；主辅不能同一本，辅修效果约为主修的 50%。
- 让玩家在 速修（青云）、聚灵（聚元）、历练（破岳）、护劫（玄龟）之间形成可解释取向；切换先结旧产速、后启用新配置。

## 2. 数据模型（schema v6 → v7）

`SCHEMA_VERSION` 6 → **7**。新增：

```ts
// TechniqueId 增：poYue(破岳诀) / juYuan(聚元诀)
// SaveState 增：
library: number;                          // 藏经阁等级 0(未建)/1/2
auxiliaryTechnique: TechniqueId | null;    // 辅修功法；与 technique 不能相同
// techniqueLevel 扩为四本书（原 qingYun/xuanGui 保留，新增 poYue/juYuan 初始 0）
```

- 藏经阁是**选择入口**，不进 `buildings` 的产速建筑，单独存 `library`。
- `migrateSave`/`normalizeSave` 对 v1～v6 旧档补默认：`library = 0`、`auxiliaryTechnique = null`、`poYue/juYuan` 等级 0；旧主修、旧书等级、资质、资源、境界、地图、镇压、每日、修仙录、在途任务全部保留。

## 3. 引擎能力

- 功法效果读取（主修/辅修按槽位区分）：
  - 修为产速 = 基础 × 资质 × 修炼室 × **青云诀（主修取 `cultivationMult`，辅修取 `auxiliaryMult`）**。
  - 灵气产速 = 基础 × 资质 × 聚灵阵 × **聚元诀（主/辅 `spiritMult`/`auxiliarySpiritMult`）**。
  - 战斗攻击 = 基础 + 装备 + 境界 + **破岳诀（主/辅 `attack`/`auxiliaryAttack`）**。
  - 护劫减伤 = **玄龟诀（主/辅 `tribulationReduction`/`auxiliaryReduction`）** + 装备减伤，仍受 40% 上限。
- `buildLibrary(state, nowMs)`：校验境界（筑基一层及以上）与灵石/残页，扣费、`library += 1`，一次提交。
- `setTechnique(state, nowMs, id)`：现有主修切换逻辑扩展为四本；校验新功法需藏经阁≥1 才可主修。
- `setAuxiliaryTechnique(state, nowMs, id)`：设置辅修；须藏经阁≥2、已有主修、且 `id !== technique`。
- `upgradeTechnique`：四本共用 Lv1 免费、Lv2 5 残页、Lv3 15 残页；新功法需藏经阁≥1 才可研习。
- 迁移与导入：校验 `library` 0~2、`auxiliaryTechnique` 合法且≠主修、无主修却有辅修拒绝、非法新功法等级/负资源/损坏任务拒绝。

## 4. 规则基线（config）

```ts
// techniques 各等级补 auxiliary 字段，并新增两本：
qingYun: { name: "青云诀", levels: [
  { pageCost: 0, cultivationMult: 1.3,  auxiliaryMult: 1.15 },
  { pageCost: 5, cultivationMult: 1.6,  auxiliaryMult: 1.30 },
  { pageCost: 15, cultivationMult: 2.0, auxiliaryMult: 1.50 },
]},
xuanGui: { name: "玄龟诀", levels: [
  { pageCost: 0,  tribulationReduction: 0.05, auxiliaryReduction: 0.025 },
  { pageCost: 5,  tribulationReduction: 0.10, auxiliaryReduction: 0.05 },
  { pageCost: 15, tribulationReduction: 0.15, auxiliaryReduction: 0.075 },
]},
poYue: { name: "破岳诀", levels: [
  { pageCost: 0, attack: 4,  auxiliaryAttack: 2 },
  { pageCost: 5, attack: 8,  auxiliaryAttack: 4 },
  { pageCost: 15, attack: 12, auxiliaryAttack: 6 },
]},
juYuan: { name: "聚元诀", levels: [
  { pageCost: 0,  spiritMult: 1.15,  auxiliarySpiritMult: 1.075 },
  { pageCost: 5,  spiritMult: 1.30,  auxiliarySpiritMult: 1.15 },
  { pageCost: 15, spiritMult: 1.50,  auxiliarySpiritMult: 1.25 },
]},

library: { levels: [
  { cost: { spiritStone: 800, page: 10 } },   // 一级：解锁两本新功法
  { cost: { spiritStone: 1600, page: 20 } },  // 二级：开放辅修位
]},
```

## 5. UI

- 洞府页：新增「藏经阁」卡片（前置境界、当前等级、两级成本/缺口、解锁内容）。
- 修炼页：四本功法卡片展示「未解锁/未研习/当前 Lv/主修/辅修」与主辅效果、下级残页成本；当前配置旁显示修为、灵气产速、攻击、护劫减伤的**数值来路**；切换前比较新旧配置，同书主辅互换明确提示。
- 人物页：属性显示破岳诀攻击来源；修仙录记录建阁/研习/升级/首次采用辅修（不补写旧档历史）。

## 6. 子阶段

1. **子阶段 A｜引擎**：schema v7 + 藏经阁/辅修字段 + 四功法主辅效果接入产速/攻击/减伤 + `buildLibrary`/`setAuxiliaryTechnique` + 迁移/导入校验；引擎测试（主辅效果、同书禁止、解锁门槛、迁移、坏档拒绝、切换结算）。
2. **子阶段 B｜界面**：洞府页藏经阁、修炼页四书主辅与切换预览、人物页攻击来源；360/390/430px 与深浅色复验。

## 7. 验收（对齐 PRD 第 4 节）

- 旧档续玩：v6 筑基/金丹旧档无损升级，不建阁仍能旧玩法。
- 藏经阁：境界未达不可建；刚好够可建；不足给差额零扣费；各级只扣一次、刷新不回归。
- 四书主辅：新书一级解锁、成本正确；旧书等级不变；同书不能双槽；主辅互换/换书预览与实战一致、免费切换不丢等级。
- 资源与时间：青云/聚元主辅、资质、建筑计算一致；挂机跨门槛同步；切换旧时段按旧倍率结算；12h 封顶不重算。
- 战斗与试炼：破岳攻击改变预估与实际；玄龟主辅、装备减伤与 40% 上限一致；结丹预览与实战一致、在途任务快照不变。
- 两种路线：资源路线与历练路线各有优势、均可通关至金丹；记录三资质模拟，不把模拟当真人试玩。
- 存档与并发：v1～v6 迁移、v7 导出导入保留主辅与阁等级；坏档拒绝现档不变；双标签建阁/换书/升级只提交一次。
