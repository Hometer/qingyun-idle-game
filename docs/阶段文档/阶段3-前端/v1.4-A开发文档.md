# v1.4 子阶段 A 开发文档：命盘与先天资质

> 配套：`docs/PRD/PRD-修仙放置游戏-v1.4-灵根与修行资质.md` R54~R57。先文档、后开发。

## 1. 范围

- 随机鉴灵 + 自行设定两种开局。
- 灵根组合（34 种：五行组合 + 雷/冰/风变异）、经脉档、悟性档。
- 经脉影响产速、悟性影响功法残页费用。
- 「修行资质」改称「修炼侧重」，洞府页手动切换（复用现有 aptitude）。
- 本子阶段只做命盘数据与效果，共鸣（R58/R59）与洗髓（R60/R61）留 B/C 段。

## 2. 数据模型

- SaveState 增：`spiritRoots: string[]`（灵根组合，五行不重复；变异单元素）、`meridians: string`（经脉档 ID）、`comprehension: string`（悟性档 ID）。
- 旧 `spiritRoot`（单五行字）迁移为「旧式灵根」标记，待用户定根；旧 `aptitude` 原样转「修炼侧重」。
- schema v14 → v15。

## 3. 概率与效果（config 单一来源）

- 灵根形态概率：五灵根 12%、四灵根 18%、三灵根 30%、双灵根 25%、单灵根 10%、变异 5%（雷/冰/风各 1/3）。
- 经脉档：闭塞 8%(×0.94)、滞涩 22%(×0.97)、平通 40%(×1.00)、通达 22%(×1.03)、天成 8%(×1.06)。
- 悟性档：迟钝 8%(×1.06)、偏慢 22%(×1.03)、平常 40%(×1.00)、聪慧 22%(×0.97)、通明 8%(×0.94)。
- 经脉倍率乘入产速；悟性倍率对功法残页费用 `floor(原价×倍率+0.5)`。

## 4. 涉及改动

1. `types.ts`：`spiritRoots`/`meridians`/`comprehension`。
2. `config.ts`：灵根池、经脉档、悟性档、概率与倍率。
3. `engine.ts`：随机鉴灵（可注入随机源）、经脉产速倍率、悟性费用倍率、迁移（旧档补默认 + 旧式灵根）、坏档校验。
4. 创建页：随机/自设分步；人物页：四项展示；洞府页：修炼侧重切换（复用现有逻辑）。

## 5. 验收

- 34 类合法灵根结果可产生、概率求和 100%；经脉/悟性独立随机。
- 经脉产速与悟性费用在页面预览与结算一致；旧档迁移后原产速不变、灵根显示「旧式」。
- 坏档拒绝；前端测试 + typecheck/lint/build 通过。
