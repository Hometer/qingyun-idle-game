# 阶段 3 · v1.0 开发文档

> 配套：`docs/PRD/PRD-修仙放置游戏-v1.0.md`（制作与装备：一座炼器台 + 一种玄铁 + 精钢剑/玄铁甲两配方）。
> 本版只做最小炼器闭环；不做九装备位、随机词条、强化/分解、新货币或新掉落表；不新增模型调用/云资源。

## 1. 目标

- 新增「炼器台」洞府建筑（一级），解锁后可在背包炼制两件固定装备。
- 新增材料「玄铁」：三秘境成功各掉固定数量 + 镇压节点持续产出。
- 两件新装备（精钢剑攻+20、玄铁甲防+15/护劫减伤+5%），固定属性、旧装备兼容。

## 2. 数据模型（schema v8 → v9）

`SCHEMA_VERSION` 8 → **9**。

- `Resources` 增 `iron: number`（玄铁）。
- `SaveState` 增 `forge: number`（炼器台等级 0/1）。
- `equipment` 增两件：`w_steel`（精钢剑）、`a_steel`（玄铁甲）。

### 三件套（自检清单第一条）

1. **旧版本迁移补默认**：`migrateSave`/`normalizeSave` 对 v1～v8 旧档补 `iron: 0`、`forge: 0`，新装备不赠送。
2. **当前版本缺字段拒绝**：`importSave` 对 v9 缺 `forge`、`resources.iron`、非法装备 ID 返回 `ok:false`。
3. **字段一致性**：`forge` 0~1 整数；`iron` 非负；`resources` 其余字段沿用现有非负校验。

## 3. 引擎能力

- 玄铁产出：
  - `settle`：镇压节点按 `0.02/秒` 产玄铁（沿用现有镇压分段结算，同 12h 上限）。
  - `enterSecretRealm` 成功时按秘境发放玄铁（灵药谷 +2、古修遗迹 +3、幽窟险境 +5），并入 `secretRealmLog.reward` 与回执。
- `buildForge(state, nowMs)`：校验境界（筑基一层）与灵石/残页，扣费、`forge=1`，单事务。
- `craftEquipment(state, nowMs, id)`：校验 `forge>=1`、配方解锁、材料足够；扣料、`inventory[id]+1`、`revision+1`，单事务。
- 迁移与导入：新增 `validateForge`、玄铁非负、新装备 ID 校验。

## 4. 规则基线（config）

```ts
forge: { cost: { spiritStone: 1000, page: 15 } },

iron: { suppressionPerSec: 0.02, realmDrop: { realm_herb: 2, realm_relic: 3, realm_deep: 5 } },

equipment 增：
  w_steel: { name: "精钢剑", slot: "weapon", attack: 20 },
  a_steel: { name: "玄铁甲", slot: "armor", defense: 15, tribulationReduction: 0.05 },

crafts: {
  w_steel: { cost: { iron: 8, spiritStone: 800, herb: 0 } },
  a_steel: { cost: { iron: 12, spiritStone: 1200, herb: 30 } },
},
```

## 5. UI

- 洞府页：新增「炼器台」卡片（前置、成本、解锁内容）。
- 背包页：炼器区展示两件配方属性、材料清单与差额；材料不足禁用并说明；炼制成功回执列出获得装备。
- 资源栏：展示玄铁（`RESOURCE_LABELS.iron`）。
- 人物页/图鉴：新装备纳入装备组展示。

## 6. 子阶段

1. **子阶段 A｜引擎**：schema v9 + 玄铁产出（settle/秘境）+ `buildForge`/`craftEquipment` + 迁移/导入校验；引擎测试（三件套、玄铁产出、炼制扣料、坏档拒绝）。
2. **子阶段 B｜界面**：洞府炼器台、背包炼器区、资源栏玄铁、图鉴装备；360/390/430px 与深浅色复验。

## 7. 验收（对齐 PRD 第 6 节，逐句抄录）

- 炼器台：未筑基不可建；刚好够可建；不足显示差额零扣费；只扣一次、刷新不回归。
- 玄铁来源：三秘境成功各掉对应玄铁；镇压持续产出；来源与数量可解释。
- 炼制：两件配方展示属性与材料；不足禁用并说明；炼制后入包、可穿戴、背包 +1、材料只扣一次。
- 属性与预览：新装备属性进入战斗预估与实战；结丹减伤与 40% 上限照常。
- 经济：不炼器仍可通关 v0.9；炼器后无失控；材料来源与成本可解释。
- 存档与并发：v1～v8 旧档无损升级；坏档拒绝且现档不变；双标签建台/炼制只成功一次。
- 界面：桌面与 360/390/430px、深浅色、减少动效可操作。
