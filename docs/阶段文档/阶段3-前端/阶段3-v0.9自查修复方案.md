# 阶段 3 · v0.9 自查修复方案

> 依据：v0.9 开发后自查（`predictSecretRealm`/`enterSecretRealm` 使用了星象加成；历练页用原始状态判断秘境次数）。
> 状态：修复 P1/P2 + 补回归测试，修复后重新复验。

## 修复总览

| 编号 | 问题 | 修复方案 | 涉及文件 |
| --- | --- | --- | --- |
| P1 | 秘境战斗误用「破军」星象 +20% 伤害 | `predictSecretRealm`/`enterSecretRealm` 的 `runBattle` 去掉 `battleDamageMult`，秘境战斗不触发、不消耗星象 | `engine/engine.ts` |
| P2 | 跨日时秘境「已探索」用原始状态 | 历练页改用 `view.secretRealmUsed` 判断已探索/禁用 | `lilian/page.tsx` |

## 逐项说明

### P1 秘境不触发星象
- PRD R46：「秘境战斗不计入『完成 3 次战斗』每日目标、不触发天气/星象限次、镇压或长期任务奖励」。
- 修复：`runBattle(stats, cfg.enemy)` 不传 `battleDamageMult`；秘境不写 `daily.astrology.used`、不写 `daily.goals.battle.progress`（现状已不写，保留）。

### P2 跨日次数显示
- 历练页 `state.secretRealmUsed` → `view.secretRealmUsed`（`view` 是 `settle(state, now)`，会随跨日把次数重置）。
- 按钮禁用与「已探索」文案都改用 `view`。

## 回归测试
1. 秘境不消耗破军：`enterSecretRealm` 后 `daily.astrology.used` 仍为 false。
2. 秘境不计入每日战斗目标：`enterSecretRealm` 后 `daily.goals.battle.progress` 不变。
3. 秘境战斗不受破军加成影响：破军（war 未用）与无星象下 `predictSecretRealm` 的 `won` 一致。

## 验收标准
- 前端 111 + 新增回归测试全绿；`tsc --noEmit` 与生产构建通过。
- 浏览器：破军未用状态下进入秘境，胜败与无星象一致；探索后破军仍可用（未消耗）、每日战斗目标进度不变。
