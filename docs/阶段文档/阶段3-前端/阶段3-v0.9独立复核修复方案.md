## 逐项说明

### P0-1 v8 坏档版本边界与完整性
- `validateSecretRealm(used, log, date, schemaVersion)` 增加 `schemaVersion` 与 `date` 参数：
  - `schemaVersion >= 8`：`date` 必须为 `YYYY-MM-DD` 格式；`used` 必须含三个秘境键且为布尔；`log` 必须是数组。
  - `schemaVersion < 8`：缺字段放行（迁移补默认）。
  - 每条记录：`realm` 合法、`won` 布尔、`at` 有限数、`reward` 非负，且 `won` 时奖励等于该秘境配置奖励、`lost` 时奖励全 0。
- 校验顺序放在 `normalizeSave` 之前，坏档返回 `ok:false` 不覆盖现档。
- 新增真实 `schemaVersion: 8` 缺字段/非法日期/奖励被改 的回归测试。

### P1-1 操作与显示统一结算态
- `game-context` 的 `startSecretRealm` 用 `view.secretRealmUsed`（或先 `settle`）判断「今日已挑战」，与历练页按钮一致。
- `predictSecretRealm` 已不读星象（上轮已修），预估与执行一致。

### P1-2 叙事就绪与复用
- 新增 `realmNarrativeLoading` 状态；`startSecretRealm` 中：若已在拉取同一秘境则直接返回；先查「秘境+当日」缓存，命中即用；未命中才 `generateEncounter`，成功后写缓存。
- `lilian` 叙事弹层：加载中显示「叙事加载中…」且「开始探索」禁用；加载完成（含模板降级）后才可点。

### P1-3 图鉴首次记录
- `renwu` 图鉴区新增「秘境」组：三秘境各显示「首次探索：已/未」「首次成功：已/未」（读 `secretRealmLog`，未发生不伪造）。

### P1-4 回执只列秘境奖励
- `confirmSecretRealm` 结果面板改用当次 `secretRealmLog.reward` 生成行；失败显示「未获秘境奖励」。

### P2-1 秘境卡信息补齐
- 秘境卡补「我方 攻/防/气血」与「今日 X/1」（用 `view.secretRealmUsed`）。

## 证据缺口（开发后补）
1. 三秘境在三种资质与典型功法/装备下的胜负模拟矩阵。
2. 三个新 AI 事件 ID（event_realm_herb/relic/deep）真实模型冒烟。
3. 双标签同日竞争：同秘境只一方成功。
4. 失败路径浏览器复验（低配角色进入秘境战败、回执「未获秘境奖励」）。

## 验收标准
1. 前端 113 + 新增回归测试全绿；`tsc --noEmit` 与生产构建通过。
2. 浏览器：真实 v8 坏档拒绝且现档不变；跨日不刷新可正常进入；叙事加载态与缓存复用；图鉴首次记录；回执不混挂机收益；秘境卡补齐；双标签同日只一次。
3. 既有 v0.7/v0.8 修复不回退。
