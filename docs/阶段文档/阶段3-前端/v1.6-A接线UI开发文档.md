# v1.6 阶段 A（接线 + UI）开发文档

> 配套：`docs/阶段文档/阶段3-前端/v1.6-A开发文档.md`。引擎（词条池 + 效果）已随提交 `c3abe5e` 完成。先文档、后开发。

## 1. 范围

- 词条生成接线：炼制/首通掉落装备时自动生成词条（可复现、确定性优先）。
- 装备详情 UI：品阶、基础属性、词条、换装对比、产速/属性变化。
- 旧档迁移：已有装备补空词条（不影响现有存档）。

## 2. 词条生成策略（确定性 + 可复现）

- 用「装备 ID + 获得序号」作种子的确定性伪随机，保证同一装备同一序号 → 相同词条（测试可复现）。
- 生产环境如需"同名装备不同词条"，后续用真实随机源 + 注入 rng 再切换，本刀先保证确定性与可测。

## 3. 涉及改动

1. `engine.ts`：`seededRng` + 确定性 `ensureAffixes(s, baseId)`（按装备 ID 哈希种子）；在 `craftEquipment`/`fightNode` 掉落处接线；旧档迁移补 `equipmentAffixes`（已随上刀）。
2. `beibao/page.tsx`：装备详情区展示词条（名称 + 数值 + 类别），炼制/掉落即时可见。
3. `renwu`（或背包）：换装对比显示词条带来的攻防血/产速变化。

## 4. 验收

- 炼制/掉落装备带 1~4 条词条，展示与结算一致；基础属性稳定。
- 特殊词条（暴击/突破率/回血/低血/战斗修为）在战报/产速中体现。
- 前端测试 + typecheck/lint/build 通过。
