## ⚠️ 结论已更正（2026-09-27 复核）

**原结论"仍偏快、建议 growthPerStage 1.22→1.17"有误，已作废。**

原因：本报告的 Python 近似模型假设「建筑功法全满级、天天吃丹药、全额在线」，**高估了产出**，导致误判"1.22 偏快"。

**真实引擎回归测试 `balance.test.ts`（从元婴起、12 小时/日、每日三次重复历练）才是可信口径**：它在 `growthPerStage = 1.22` 下到达鸿蒙正好落在 42~56 天；实测改成 1.17 后变为 69 天，超过 56 天上限。

**最终结论：`growthPerStage` 保持 1.22，无需修改。**
