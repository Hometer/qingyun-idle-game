# v1.3 真实材料模拟报告

> 2026-09-27。纳入修为/灵气/灵石/残页/玄铁/灵材的逐日供给与消耗，贪心玩家模型（每日满额 + 即时升级建筑/功法）。

## 一、结果

| 登录 | 到鸿蒙道祖十层 | 最终培养 |
| --- | --- | --- |
| 1 次/天 | 约 35 天 | 修炼室 Lv8、青云诀 Lv8、藏经阁 Lv4 |
| 2 次/天 | 约 20 天 | 修炼室 Lv8、青云诀 Lv7、藏经阁 Lv4 |

## 二、结论：仍偏快，需下调境界产出增长

当前 `realmProduction.growthPerStage = 1.22` 使产出增长快于成本增长，即使计入材料瓶颈，理想+材料模型仍在 20~35 天，**低于 42~56 天目标**。

**敏感度（1 次登录/天，理想修为主线）**：

| growthPerStage | 到鸿蒙天数 |
| --- | --- |
| 1.22（现行） | 33 |
| 1.18 | 43 |
| 1.15 | 54 |
| 1.12 | 70 |

## 三、调整表（建议）

| 项 | 现行 | 建议 | 依据 |
| --- | --- | --- | --- |
| `realmProduction.growthPerStage` | 1.22 | **1.17** | 1 次登录落到约 45 天，居中于 42~56 |

## 四、局限（如实）

- 灵石/残页/灵材收入用随境近似公式估算，非逐节点精确值；精确值需按 config 逐节点核算。
- 贪心玩家模型假设每日满额 + 即时升级，真实玩家更慢。
- 因此上表是「量级」判断，非精确承诺；精确落点仍需真人试玩校准。

## 五、下一步

- 按调整表把 `growthPerStage` 1.22 → 1.17，重跑测试与逐境模拟。
- 之后交产品经理真人试玩 + 真机验收。
