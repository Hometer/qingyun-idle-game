## 必须问（本轮不超过 5 个）

### 问题 1：模型厂商与每月成本上限（D4）
- 为什么重要：决定用哪家模型、每月的钱花在哪，也影响数据是否出境（和问题 2 联动）。
- 选项：A 国产大模型（DeepSeek / 智谱 GLM / 通义千问）　B 海外（OpenAI / Claude 等）　C 不限，选最便宜好用的
- 推荐：**A**。半文半白的修仙文案国产模型性价比高、中文好，且数据不出境。
- 不选的后果：选 B 则数据大概率出境、成本更高；选 C 则后续还要再定一次。无论选哪家，请给一个**每月模型费用上限**（比如 50 元 / 100 元，超了就提醒你）。

### 问题 2：AI 际遇会发少量玩家信息给模型厂商，是否接受（D7）
- 为什么重要：AI 写际遇文案需要把"姓名或称呼、灵根、境界、地图、最近两条修行摘要、选项含义"发给模型服务商，这算隐私边界，必须先说清。
- 选项：A 接受，但只发最少上下文、发给国内厂商（数据不出境）　B 不能把任何玩家信息发给第三方　C 无所谓，海外也行
- 推荐：**A**。PRD 已经限定只发最少上下文，再叠加上国内厂商，隐私与产品体验兼顾。
- 不选的后果：选 B 等于砍掉 AI 际遇、全程用模板文案，丢掉本产品最大的差异点；选 C 则玩家昵称可能出境。

### 问题 3：MVP 做完后上线给谁用、云费用预算、能否办企业认证（D9）
- 为什么重要：决定上线路线和花钱规模。企业实名认证通常要几天，能办的话建议现在就去办，与开发并行。
- 选项：A 先小范围（朋友/自测）用便宜方案，月预算 ≤100 元　B 直接对外公开上线，需企业认证+域名，预算更高　C 暂时不上线，只在本地跑
- 推荐：**A**。先小范围验证，成本最低、认证门槛低，跑顺了再扩大。
- 不选的后果：选 B 要等企业认证数天且费用更高；选 C 则别人无法体验，无法收集试玩反馈。另请明确：**能否办云平台企业实名认证**（能/不能/不确定）。

### 问题 4：AI 代理后端要不要加访问门槛（D5）
- 为什么重要：AI 后端是匿名公开接口，谁都能调，不加门槛可能被刷量、模型费用失控。
- 选项：A MVP 匿名访问 + 服务端限流 + 邀请码　B 完全匿名不限　C 正式账号登录
- 推荐：**A**。和"单机无账号"定位一致，又能防刷。
- 不选的后果：选 B 有费用失控风险；选 C 增加开发量、且与"无账号"定位冲突。
