# 技术适配声明

> 对象：`docs/PRD/PRD-修仙放置游戏-v0.2.md`（「青云修仙录」）
> 生成日期：2026-09-24
> 阶段：1 技术适配（进入阶段 2 开发前）

## 1. 产品形态判断

- 产品类型与核心任务：移动端优先的**单机网页文字放置游戏**。玩家在浏览器本地进行收益收取、小进阶、历练战斗、镇压、洞府升级、渡劫；AI 只在"际遇事件"时生成半文半白文案，游戏规则、数值、选项、分支与奖励全部由确定性引擎决定，AI 故障用模板文案降级。
- 核心交互：**其他**（游戏状态操作 + 局部单次 AI 文案生成，4 秒超时、失败即模板）。
- 开发路径：**纵向切片**。理由：游戏引擎与存档必须跑在浏览器端（PRD 明确要求），且"文案是否可读、渡劫预览是否可理解"是核心价值、必须"用眼睛看、亲手操作"才能验收，故采用"最小引擎 + 最小界面 + 薄 AI 代理 + 真实模型"端到端验证，而不是先做纯后端再套壳。
- 当前阶段范围：**阶段 2（核心能力）**——确定性游戏引擎核心（收益结算、小进阶、战斗、天劫、存档与离线结算、导入导出）、AI 文案代理后端（结构校验、内容审核、超时、限流、降级、模板库）、mock 自动化测试、真实模型冒烟、最小验收界面。正式五入口前端留到阶段 3。

## 2. 采用的默认方案

| 方案 | 采用原因（一句话） |
| --- | --- |
| AI 代理后端：Python 3.12 + FastAPI + Pydantic | 承载模型调用、结构化输出校验、内容审核、超时、限流、降级，是手册默认后端基线 |
| 后端测试：pytest | mock 测试校验接口结构、错误路径、降级 |
| 游戏引擎 + 界面：TypeScript + React（最终 Next.js + Tailwind） | 引擎必须在浏览器运行（PRD 6.1），与界面同源，符合手册 Web 默认栈 |
| 引擎测试：Vitest（TypeScript） | 纯状态转换可复现，覆盖收益/战斗/天劫/离线结算 |
| 模型调用：国产大模型官方 SDK | D4 已定国产（DeepSeek / 智谱 GLM / 通义），具体型号在阶段 2 技术开发文档定 |
| Git + .gitignore | 已就绪，密钥不入仓库 |

## 4. 偏离或暂缓的默认方案

| 默认方案 | 替代方案 | 原因 | 影响 | 未来重新评估条件 |
| --- | --- | --- | --- | --- |
| 单体后端承载业务逻辑 | 业务核心（游戏引擎）跑在浏览器端，后端仅为薄 AI 代理 | PRD 6.1 明确"游戏状态与规则配置由网页客户端管理，存档写入 IndexedDB" | 引擎用 TypeScript 而非 Python；后端规模很小 | 若 P2 做账号/跨设备存档/PVP，再评估后端扩为有状态服务 |
| 后端先行（默认路径 A） | 纵向切片（路径 B） | 交互与文案质量是核心价值，引擎又必须跑在浏览器 | 阶段 2 即需要最小界面参与验收 | 核心链路验证通过后，阶段 3 再铺正式前端 |
| 正式前端五入口 | 阶段 2 用最小验收界面，正式视觉推迟到阶段 3 | 先验证核心链路，不提前打磨视觉 | 阶段 2 验收界面不等于最终视觉 | 阶段 3 按前端手册展开 |

## 5. 强制底线检查

- 密钥与隐私：**通过**。模型密钥只存后端 `.env`（已入 `.gitignore`），不入前端、不入仓库、不在对话/日志/提交回显；AI 只收最少上下文（称呼、灵根、境界、地图、两条修行摘要、选项含义），日志不记姓名与完整存档。
- 数据与任务可恢复：**通过**。存档存浏览器 IndexedDB，支持导出/导入/手动重置；资源变更按事务提交，离线结算按 `delta` 与 `lastSettledAt` 幂等处理，刷新/多标签不重复结算。
- 输入输出校验：**通过**。后端用 Pydantic 校验 AI 返回结构（事件 ID、选项 ID 集合、长度、占位符），并做内容安全与文风审核；AI 响应中的奖励/数值字段一律不接收，奖励由本地引擎按配置结算。
- 错误与日志边界：**通过**。统一 `{"error":{"code","message"}}`，不泄露堆栈；本阶段不用 SSE，故"SSE 以 done/error 收尾"为 N/A；日志脱敏。
- 测试与真实模型验收：**计划**。引擎用 Vitest mock 测试（收益/战斗/天劫/离线/导入导出）；AI 代理用 pytest mock 测试（校验、审核、超时、限流、降级）+ 真实模型冒烟。真实冒烟需真实 Key，无 Key 时如实标注"待验"，不用 mock 冒充。D2 验收标准在首次真实冒烟用 5~10 条真实样例打分确定。
