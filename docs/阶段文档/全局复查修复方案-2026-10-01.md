# 全局复查修复方案（2026-10-01 第二轮）

> 依据 `docs/阶段文档/全局复查-2026-10-01/全局复查报告.md`（基线 `03318bc`）。本轮 7 组 P1、9 组 P2，按报告第七节顺序：先修 P1-01/02/03/04 的存档与日限制，再修 P1-06/07 的费用与内容保护，再修 P1-05 候选闭环，最后补 P2 迁移与可见预览。每批保留现有测试并补回归。

## P1 修复要点

### P1-01 跨日委托 / 旧任务导入失败
- 委托实例身份与目标类型 ID 分离：`Commission` 增 `instanceId`（或让 `id` 含生成日期），关系校验不再把「同类型目标」误判为「同一实例」。跨日相同目标 ID 不同，不再误拒。
- 旧 v17 在途任务：`validateLongTask` 增 `ver` 参数，`ver < 18` 时允许缺 `effectiveMinutes`（导入后由 `migrateSave` 从 `endAt-startAt` 回推补齐）。

### P1-02 坏档仍能覆盖进度 / 刷新崩溃
- 补全必需结构校验（版本相关，v18 必需字段缺失即拒绝）：`daily.goals`/`daily.weather`、`meridians`/`comprehension` 枚举、`rewardedDan` 非负、`quenched` 元素合法、`learnedNewTechs` 须已解锁、`marrowHistory` 类型/非负、`tribulationLog`/`jindanTrial` 结构、`spiritRoots` 非空。
- 委托奖励与 action 校验：奖励各字段非负有限（且拒绝超界值如 `1e30`）、`action` 须在已知动作集合内。
- 读档初始化失败需安全恢复（读档异常不冒充空档，初始化写失败不卡在未 ready）。

### P1-03 旧档灵材迁移 NaN + 补偿
- `migrateSave` 补齐五种灵材字段（缺失补 0）。
- `schemaVersion < 14` 的旧档：遍历已首通节点，按 `materialForStage` 一次性补发应得灵材（4 枚/节点），补发后字段存在、后续迁移不重复；历史秘境奖励按原版本验证。

### P1-04 首通后同日再接 + 际遇回拨
- `CommissionState` 增 `acceptedDate`（当日已接取日期）；`acceptCommission` 同日已接取则拒绝；`claimCommission` 不重置该事实。
- 首通刷新候选仍可更新目标，但不得授予新日额度（接取受 `acceptedDate` 拦截）。
- `rollEncounterDay` 改为 `today > lastTriggerDate` 才重置（日期高水位），回拨不刷新际遇额度。

### P1-05 可完成候选 + 刷新实际保存
- 候选生成与接取校验共享同一套条件：战斗候选核对挑战可行；制作候选核对境界门槛、所需建筑/炼器台等级（升级建筑看下一级 gate、炼制看 forgeLevel、炼丹看炼丹炉等级），只生成当前可完成目标。
- `acceptCommission` 目标失效时返回带新状态的 `Result`（重新生成候选并返回 `{state}`），前端刷新页面；失败不返回可丢弃的临时状态。

### P1-06 预算重试越过 / 坏账本
- `llm.py`：每次重试前 `budget_exceeded(estimate)` 检查并预留，越界即停止、降级模板。
- `budget.py`：`_load` 对损坏/错误形状账本安全降级（返回 `{}` 并告警，不抛异常、不静默清空语义），`current_spend_rmb` 容忍 `[]`/`{}`/非 dict。

### P1-07 AI 选项文字绕过审核
- `moderation.validate_result` 对每个选项的 `option_text` 也执行 `check_content`（血腥/收益暗示/数字），不合格整体降级模板。

## P2 修复要点（按需分批）

- **P2-01 淬炼开放**：剑/法衣淬炼按下一境开放（配置化逐装备允许境界），预览与执行一致。
- **P2-02 旧式灵根免费定根**：旧档在玩家主动确认前保持旧效果，确认后一次性免费定根，不占洗髓机会。
- **P2-03 旧装备迁移空词条**：无实例旧装备补空词条（不加随机词条），保留数量/穿戴/基础效果。
- **P2-04 页面与引擎门槛一致**：洞府/背包/秘境预览共用门槛、费用、效果与最高级状态。
- **P2-05 装备图鉴归并实例**：实例归并到基础装备图鉴。
- **P2-06 资质影响与动作预览**：功法成本按悟性折算显示、洗髓/共鸣/侧重/重铸补前后对照。
- **P2-07 委托次日回应**：领奖生成回应但标记待回应，次日可辨认转移，不再发奖励。
- **P2-08 AI 上下文与本地模板**：发送当前合法根性；本地模板使用事件对应文案。
- **P2-09 存储故障反馈**：读写失败保留进度并说明恢复路径。

## 复验要求
每批：保留现有测试 + 针对失败机制补回归；浏览器独立来源走真实动作→导出→导入→刷新→重启；资源只结算一次；不改 PRD、不删测试、不赠送无限资源关闭问题。
