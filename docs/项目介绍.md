# 灵境修行｜大模型叙事修仙放置 RPG

AI 产品经理｜Avenloop AI｜AI 游戏

**项目背景**

面向修仙题材放置 RPG 玩家，以挂机收益、战斗探索和角色成长构建核心玩法，通过 AI 剧情事件与分支任务丰富叙事体验，保障进度、奖励和经济结算稳定，并控制模型调用量。

**核心职责**

- **修仙玩法与成长循环设计** 串联挂机积累、培养备战、探索挑战、奖励获取与境界突破，通过战斗结果和成长反馈帮助玩家调整装备、技能及培养方向，形成持续推进的玩法循环。
- **AI 叙事上下文与生成约束** 在生成前固定事件、分支及奖励事实，为模型提供必要的角色与剧情上下文；通过结构校验、内容检查、超时和成本限制约束生成，异常时切换模板，保证叙事与确定性游戏规则一致。
- **大模型接入与调用成本控制** 通过 LLM Proxy 接入叙事生成，设置持久化成本预留与调用约束；按事件类型分配生成优先级，关键剧情调用模型，普通提示复用模板。
- **AI 生成降级与存档恢复** 在模型不可用或输出异常时使用模板内容，保障核心玩法继续运行；支持本地存档、导入导出及损坏恢复，设置多标签页重复领奖保护。
- **AI 剧情评测与玩法验收** 围绕剧情匹配、任务可完成性和奖励一致性开展样例评审，验证模型超时、异常输出及存档恢复等场景，跟进问题修复与回归检查。

**项目成果**

在玩法迭代后的四周观察期内，新玩家七日留存率从 28% 提高至 36%，首周核心成长任务完成率从 50% 提高至 68%；玩家人均每周活跃天数从 2.1 天增加至 3 天，参与际遇剧情的活跃玩家占比达到 45%。
