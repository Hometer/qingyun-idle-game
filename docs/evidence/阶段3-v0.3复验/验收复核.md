# v0.3 独立验收复核

> 2026-09-24；对照 `docs/PRD/PRD-修仙放置游戏-v0.3.md` 的 R01～R17。结论：**未通过，暂不进入上线阶段**。本轮只复核，不改游戏业务代码。

## 复核方式与已通过项

- 在隔离的生产构建上用真实浏览器走了新档创建、模板际遇、首次战斗与镇压、首次小进阶、人物/图鉴、360px/390px/430px 与桌面、深色模式、v0.2 旧档打开、导入和恢复。新旧测试档使用不同来源隔离，未重置或导入原有本地预览存档。恢复 5173 开发服务时另打开一次原预览页，该页按现有规则自动结算了离线收益。
- 前端 `npm test`：**32/32**；后端 `pytest -q`：**14/14**；前端 `npm run typecheck` 与 `npm run build`：通过。前端没有配置 Lint 脚本。
- 战前节点详情能显示敌我属性、首胜/重复奖励、预计胜负和镇压产出。导入有效旧档后，基本资源、境界和镇压状态保留；正常备份存在时，“恢复导入前档”可恢复。360px、390px、430px 页面未见横向溢出，深色模式可切换。
- 已检查本地模型密钥未被 Git 跟踪，当前前端静态产物也未检出该密钥。未在本轮调用真实模型，v0.3 的 AI/模板切换链路仍待单独实测。
