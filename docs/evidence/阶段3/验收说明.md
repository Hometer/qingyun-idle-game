## 二、产品经理照着点（本地验收）

前提：后端（8001）+ 前端（5173）都在跑，浏览器打开 http://localhost:5173。

1. 首次打开 → 填道号、选灵根 →「踏入仙途」。
2. 底部五个入口（修炼/历练/洞府/背包/人物）来回切换，页面均正常。
3. 顶部「领取收益」资源增加；刷新后同一时段不重复。
4. 修炼页「小进阶」；炼气圆满后出现「渡劫预览」与「开始渡劫」。
5. 历练页点「战斗」看战报；点「镇压」；战斗后可能弹「际遇」，显示 AI 文案（无 Key 或超时为模板），选选项奖励到账。
6. 洞府升级建筑、背包炼丹/穿装备、人物页导出→重置→导入。
7. 手机/375px 窄屏下五入口与按钮可点可用。
