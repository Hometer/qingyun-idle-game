## 二、产品经理照着点（本地验收）

前置：后端（8001）+ 前端（5173）都在跑，打开 http://localhost:5173。

1. 修炼页「闭关」选 30/60/120 分钟 →「开始闭关」→ 页头出现「闭关 · X 分钟 · 剩 X 分」。
2. 页头任务栏点「中止」→ 二次确认 → 任务清空、无奖励。
3. 历练页「持续历练」→ 选已首通节点 → 稳行/险行 → 时长 → 可勾「护行阵」→ 看「预计可胜 / 预计所得」→「开始持续历练」。
4. 到期领取：把浏览器存档里的 `longTask.endAt` 改到过去（或等满时长）→ 刷新 → 任务栏显示「可领取」→「领取」→ 结果面板显示任务所得。
5. 任务进行中仍可即时战斗、换装、升级建筑、渡劫（互不阻塞）。
