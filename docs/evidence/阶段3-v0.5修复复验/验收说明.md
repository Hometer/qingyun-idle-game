# 阶段 3 · v0.5 再复核修复复验

日期：2026-09-25。针对 `docs/evidence/阶段3-v0.5再复核/验收复核.md` 列出的 3 项 P0、2 项 P1 的修复，进行代码核对 + 单元测试 + 浏览器双标签复验。结论：**全部修复到位，本轮复核的阻塞项已关闭**。

## 修复内容

| 项 | 问题 | 修复 |
| --- | --- | --- |
| P0-1 | 重置的存档被旧标签页复活 | `storage.ts` 新增持久化「代次 generation」（meta 记录）；`clearSave`/`replaceSave` 递增代次，`persistSave` 先校验代次再校验修订号；`game-context.tsx` 维护 `genRef`。旧标签代次不匹配即拒写 |
| P0-2 | 一次并发冲突后旧标签持续无法写入 | `game-context.tsx` 删除从内存 state 推导 `baseRef` 的 `useEffect`；`baseRef` 只在读档/写档成功/重置/导入时更新，冲突后以数据库真实修订号重建基准 |
| P0-3 | v4 坏档可导入并在领取时抛错或产生负资源 | `engine.ts` `validateLongTask` 全量校验（ID/类型/难度/护行阵/时长/起止关系/规则版本/地图节点/非负快照与奖励），新增 `validateLongTaskResult`；`taskNodeName` 改可选链防抛错 |
| P1-1 | 导入文件缺入口校验与读取失败处理 | `game-context.tsx` 加 2MB 上限、`.json` 后缀校验、`onerror`/`onabort` |
| P1-2 | 长期任务时间信息显示不完整 | `labels.ts` 新增 `fmtTime`/`fmtDuration`/`fmtRemaining`；Shell 显示开始/预计结束/剩余时间，修炼/历练页显示预计结束，人物页显示 `completedAt` |
