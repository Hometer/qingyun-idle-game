## 可直接发给 DeepSeek 的修复清单

### P0-1：v6 缺整张云岭古道地图的坏档被当作合法旧档导入

- **复现**：从正常导出档复制一份，保留 `schemaVersion: 6`，删除 `maps.map_yunling`，调用 `importSave(JSON.stringify(...))`。独立脚本实测返回 `ok: true`，导入后的三个云岭节点均变为默认的 `unlocked: false, cleared: false`。若原档已经首通，这会静默抹掉地图进度。此前 v0.7 已把同类问题列为 P0 并修复。
- **定位**：`frontend/src/engine/engine.ts:1419` 用 `schemaVersion < SCHEMA_VERSION` 判断能否缺失地图；当前 `SCHEMA_VERSION=7`，因此 v6 被误认为“还没有云岭地图”。`normalizeSave` 在 `:1677` 合入默认地图，造成进度重置。现有回归测试 `engine.test.ts:1026` 构造的是当前 v7 档，名称写 v6，漏掉了真正的 v6 输入。
- **修复验收**：按**地图实际引入版本**判断缺失是否可迁移。v1～v5 合法缺云岭地图可补默认；v6 缺整张云岭地图或任一必需节点应返回 `ok: false`，不抛异常、不替换当前存档；v6 合法档迁移后地图与结丹记录不变。新增真实 `schemaVersion: 6` 回归用例。

### P1-1：主辅切换前没有关键数值对比，切换后才看得到结果

- **复现**：在二级藏经阁、已有主辅功法的修炼页点击另一门功法的“主修”或“辅修”。按钮直接调用变更并持久化，只显示“改修成功”或“辅修已调整”；没有切换前后的修为/灵气产速、攻击、护劫减伤对比，也没有主辅互换的明确预览。现有[四功法截图](../阶段3-v0.8/02-四功法主辅设置.png)也只显示当前装配。
- **定位**：`frontend/src/app/xiulian/page.tsx:174-185` 直接调用 `setTechnique`/`setAuxiliaryTechnique`；`frontend/src/lib/game-context.tsx:438-470` 直接提交。修炼页“产速与来源”只列修为和灵气，攻击及护劫减伤的当前来源也未在同一配置区呈现。与 PRD R42、R44 不符。
- **修复验收**：选择功法时先展示变更前后四项关键值及主辅互换关系，玩家确认后提交；预览与引擎实际结算共用规则，成功回执在持久化后出现。覆盖切到新书、主辅互换、不同等级以及移动端。

### P1-2：修仙录漏记功法研习、升级和首次辅修

- **复现**：在二级藏经阁档中首次辅修破岳诀，再升级当前主修。独立脚本实测 `milestones` 仍只有角色创建记录；仅“藏经阁升级”会追加修仙录。人物页只能回看现有记录，无法回看这些完成动作。
- **定位**：`frontend/src/engine/engine.ts:739-813` 的 `setTechnique`、`setAuxiliaryTechnique`、`upgradeTechnique` 只写 `recentLogs`；`pushMilestone` 仅在 `buildLibrary` 中调用。与 PRD R44 不符。
- **修复验收**：实际完成的首次研习、功法升级和首次采用辅修写入修仙录；普通免费切换不刷大量记录；旧档不补造历史，刷新及导出导入后记录仍在。

### P1-3：旧档升级前备份失败仍继续迁移写档

- **复现依据**：加载低于 v7 的旧档时，`frontend/src/lib/game-context.tsx:171-173` 对 `backupSave` 的失败使用 `.catch(() => {})`，随后继续 `migrateSave` 与 `persistSave`。IndexedDB 备份失败时，可能只剩已迁移的存档，没有 PRD R45 要求的可恢复原档。
- **修复验收**：模拟备份写入失败；旧档迁移不得以“成功”回执继续覆盖，页面给可理解的失败提示，原档保持可恢复。备份成功后再进行迁移。

### P2-1：百分比和藏经阁成本反馈不精确

- **复现**：玄龟诀 Lv1 辅修的真实减伤是 2.5%，Lv3 是 7.5%，修炼页 `Math.round(... * 100)` 分别显示 3% 和 8%（`frontend/src/app/xiulian/page.tsx:15`）；渡劫/结丹预览同样取整显示。洞府页资源不足只显示“资源不足”，不显示灵石与残页各差多少（`frontend/src/app/dongfu/page.tsx:94-99`）。
- **修复验收**：保留 2.5%/7.5% 的显示精度，预览和实际减伤一致；藏经阁两级均显示两种资源的具体差额，成功后显示本次扣费和新解锁内容。
