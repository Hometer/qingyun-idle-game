## 二、产品经理照着点（本地验收步骤）

前提：后端与前端两个服务都在跑（见 README「启动方法」；地址 http://localhost:5173）。

1. 打开 http://localhost:5173，填姓名、选灵根，点「踏入仙途」。
2. 点「领取挂机收益」，资源增加；刷新页面，同一时段收益不重复领取。
3. 点「小进阶」（修为/灵气达标后），境界提升、资源按门槛扣除。
4. 历练区点「野狼」的「战斗」，看到战报；点「镇压」后看到该图镇压产出。
5. 触发际遇，看到半文半白文案（无 Key 时为模板），点选项后奖励到账（如灵石 +30、灵草 +5）。
6. 点「查看劫势」看五波伤害与减伤预览（需炼气圆满，可通过导出存档里改境界或等我给测试档）。
7. 「存档」区导出 → 重置 → 导入，进度恢复；导入损坏文件不覆盖。
8. 手机/窄屏下核心按钮可点可用。

## 四、接口冒烟记录（无 Key 已实测）

- `GET /health` → `{"status":"ok"}`
- `POST /api/v1/encounter/generate`（无 Key）→ 返回 `source: template` 的模板文案
- 未知事件 → 422 `{"error":{"code":"INVALID_REQUEST",...}}`
- 选项与事件不匹配 → 422 统一错误结构
- 限流 / 邀请码 → 429 / 403（pytest 已覆盖）

> 真实模型冒烟（source: model、真实延迟、token 用量、成本、样例打分）待 Key 后补做，如实标注"待验"。
