# 青云修仙录国风视觉改版：本轮验收

日期：2026-09-28。阶段 3 的视觉增量；保留当前游戏规则、五个主入口、存档和深浅色设置。本轮另修复了人物页读取 v1.6 装备实例 ID 时崩溃的问题。

## 视觉方向与来源

- 参考《一念逍遥》[官方介绍](https://www.taptap.cn/app/159465/all-info)中的写意水墨、云山与留白，以及《凡人修仙传》[动画页面](https://www.bilibili.com/bangumi/media/md28223043)的修行旅途氛围。只借鉴视觉语汇，不使用两部作品的角色、标志或画面。
- 采用夜色云海山门、朱砂小印、宣纸卡片、金线与宋体标题；去掉页面中大量英文字样。导航用“仙途五卷”，历练节点用序号和守关印记。
- 云海山门背景为本轮用内置 ImageGen 生成的原创插画，项目文件 `frontend/public/images/ink-clouds.jpg`，1942×809、约 351 KB。生成提示词要点：夜色水墨云海山脉、右侧月亮与远处山门、左侧留给文字、无人物和文字、无现有作品元素。原始 PNG 经 JPEG 压缩后用于网站。

## 页面变化

- 共用境界面板、资源格、桌面侧栏、手机底部导航、页标题和内容卡统一视觉；建角封面使用同一原创插画。
- 历练地图增加山门节点、支线与守关印记，保留原有地图、难度、战斗、镇压操作。
- 人物页按装备实例 ID 找到基础装备后显示名称与基础属性，避免 v1.6 存档进入人物页时 `EQUIPMENT[id]` 为空而报错。
- 图片使用项目本地静态资源，不在运行时请求第三方站点。

## 实测

- 浏览器在隔离测试来源新建角色、选择模板、领取收益、进入人物页，页面正常。对已有测试档访问修炼、历练、洞府、背包、人物五页均正常。
- 390、768、1280、1440px 检查五个主页面；均未出现横向溢出。桌面和手机检查了建角、修炼、历练地图；深色模式做浏览器视觉检查。物理真机仍待验。
- 前端测试 183/183、后端测试 20/20；类型检查、Lint、生产构建通过。Lint 有两条现存警告：`engine.ts` 未用变量、`game-context.tsx` Hook 依赖。生产服务已在 5173 重启，页面和本地插画均返回 200。
- 本轮没有调用真实模型；AI 文案代理与游戏数值没有修改。v1.6 整改项的独立复验仍是另一项待办，本文件不代替该复验。
