## 可以自己核对的内容

本轮独立地址为 http://127.0.0.1:5187，常规角色地址仍是 http://localhost:5173。端口和主机名都会区分浏览器存档；请不要在常规角色上注入坏档或修改日期。

1. 打开独立地址 → 用一个测试道号建角 → 选择“仅用模板” → 点“踏入仙途”。人物栏显示道号和炼气一层，算建角成功。
2. 点底部或左侧“历练” → 在野狼一行点“战斗” → 关闭战斗回执 → 在际遇选择一个选项 → 关闭回执 → 点野狼“镇压”。野狼旁显示镇压中，人物页修仙录增加记录，算主循环通过。
3. 普通首胜后看“山河委托” → 接取野狼挑战 → 切“挑战 · 奖励提升” → 野狼“备战” → 选“守拙” → “开战” → 关闭回执 → 选择奖励并确认。委托进入“已交付”，出现“青崖明日回应”，算正常委托闭环通过。这里也可直接看到早期只有一件候选的遗漏。
4. 点“人物” → “导出存档”；导出提示与时间应更新。导入一个健康 JSON 时应先确认覆盖。**下载文件的完整验收仍待复核**，本轮工具没有捕获 Blob 下载事件，未把内部读取生成的测试 JSON 冒称为下载验证结果。
5. 关闭重开或刷新页面，正常角色应恢复。异常档专项请看下方截图和报告，避免拿自己的角色做破坏性测试。

独立预览使用本轮生产构建及模板后端；真实模型六个后续事件由后端另行调用，返回原文在[真实模型样例](真实模型样例.json)。6/6 返回模型来源；文案风格与引文质量仍可按既定标准人工审阅，不能把请求成功等同每条内容已获产品经理认可。
