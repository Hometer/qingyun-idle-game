# 「青云修仙录」产品需求文档 v0.6

> 范围已确认：2026-09-25，产品经理回复“按你推荐来”。本文定义 v0.6 的已确认需求，开发尚未启动。依据[版本候选清单](../阶段文档/规划/参考站体验对照与v0.3候选清单.md)的“随机灵根资质、修炼倍率、概率小进阶”方向，以及 [v0.5 PRD](PRD-修仙放置游戏-v0.5.md)与[最新复验记录](../evidence/阶段3-v0.5修复复验/验收说明.md)起草。v0.2～v0.5 未被本文明确改动的规则继续有效。

## 1. 版本判断与目标

v0.5 的 3 项 P0、2 项 P1 已修复复验，自动检查和全新空档首次筑基闭环已通过；**v0.6 范围现已确认**。最新复验的阶段闸门第 7 项仍为“部分”：尚缺完整真机/各宽度走查。第 5 项仅记录“未发现已跟踪密钥文件”，第 6 项列出的恢复验证是刷新/双标签/重置，尚需对最新修复版补齐前端产物审查与关闭重开/服务重启证据。自然等待 30 分钟到期的验证也尚未完成，列为非阻塞观察。正式启动 v0.6 开发前须关闭阶段闸门的证据缺口，不能把 PRD 确认当成 v0.5 阶段完成证明。

本版拟让新角色在现有炼气至筑基成长中获得**可解释、可控的修行取向**，并让小进阶有“稳妥或冲关”的选择。五行灵根仍由玩家自选，继续只用于角色设定与际遇文案；新增的“修行资质”与五行分开，避免把某一种灵根变成唯一强势选择。概率只参与玩家主动选择的冲关，不影响普通收益、历练胜负、长期任务结算和天劫五波模拟。

**已确认的取舍**：新增可自由选择的资质取向，并提供有失败保底的冲关选项；五行灵根仍同强度，玩家仍可选择必成功的稳妥进阶。下文数值是首轮试玩基线，平衡调整以模拟和试玩结果为依据。

## 2. 范围与玩家流程

1. 创建角色时，玩家选道号与五行灵根。系统给出一个随机推荐的修行资质，同时明确显示其修为、灵气产速倍率；玩家可在确认创建前改选三种资质中的任一种。创建后资质固定，不以反复重置刷取优势。
2. 修炼页与人物页显示资质名称、两种产速倍率及实际每秒产速。点开“产速来路”可看到基础值、资质、建筑、功法的计算关系。
3. 炼气一层至圆满的三次小进阶，在资源达标时由玩家选择“稳妥进阶”或“冲关进阶”。按钮前展示本次资源消耗、成功率、失败损失、保底进度及成功/失败后的状态；玩家再次确认才提交。
4. 成功后进入下一层并保存记录；失败后境界不倒退，记录消耗和保底进度。刷新、双标签竞争或存档导入后，已有结果保持一致，不能重复扣费或重复判定。
5. 炼气圆满至筑基仍沿用现有手动渡劫与五波劫势规则，不纳入本版概率小进阶。

## 3. 规则基线

以下数值用于第一轮模拟和试玩，须集中配置；界面预览与实际引擎读取同一套配置。若试玩显示某一路线明显占优或首次筑基时间被拉长，先调整本表并复验，再决定是否发布。

### R33 修行资质与公平开局

| 资质 | 修为产速倍率 | 灵气产速倍率 | 说明 |
| --- | ---: | ---: | --- |
| 均衡 | 1.00 | 1.00 | 与 v0.5 完全一致 |
| 凝神 | 1.05 | 0.95 | 略偏修为 |
| 聚灵 | 0.95 | 1.05 | 略偏灵气 |

- 三种资质都是**可选的取向**，没有高低品质、抽卡稀有度或额外付费。随机只决定创建页初始推荐项；玩家可在建档前自由选择，无需反复清档。新角色默认的五行灵根不决定资质分布或倍率。
- 实际修为产速 = 原有基础修为产速 × 资质修为倍率 × 修炼室倍率 × 主修功法倍率；实际灵气产速 = 原有基础灵气产速 × 资质灵气倍率 × 聚灵阵倍率。保持现有显示精度与资源结算精度，产速展示不能高于实际到账。
- 资质影响**资质启用后的普通在线/离线修为与灵气产出**，以及新开始的闭关快照。已开始的 v0.5 闭关继续按旧快照结算；即时战斗、持续历练、镇压、每日目标、天气/星象一次性奖励、装备属性及天劫伤害均不乘资质倍率。
- 首轮平衡检验须比较三种资质完成炼气三次进阶及首次筑基的用时与资源剩余。目标是无一档在典型路线下对所有关键节点都严格占优；若不成立，调倍率或收窄差异，不增加“劣等资质”层级。

### R34 两种小进阶方式

当前三段门槛继续作为“冲关”的完整成本：一层→二层 120 修为/20 灵气，二层→三层 300/50，三层→圆满 700/100。

| 方式 | 成功率 | 成功时消耗 | 失败时消耗 | 结果 |
| --- | ---: | --- | --- | --- |
| 稳妥进阶 | 100% | 完整成本 × 1.15，各资源向上取整 | 无失败 | 达标后必定进入下一层 |
| 冲关进阶 | 初次 80%；同一层首次失败后 90%；第二次失败后 100% | 完整成本 | 完整成本的 20%，各资源向上取整 | 失败不降境界、不掉装备；最多两次失败 |

- 稳妥进阶不要求玩家先冲关；若玩家已经冲关失败，仍可改选稳妥进阶。成功进入下一层后，保底计数归零；不同层的失败次数不相互继承。若选择稳妥进阶，界面不得仍显示随机失败风险。
- 两种方式都要在点击前有足够的**本次成功成本**；冲关失败只扣表中失败成本。成功或失败仅消费一次，资源不得为负。按钮显示当前保底次数与准确成功率，不出现含糊的“成功率较高”。
- 失败记录要写清哪一层、当次概率、实际消耗和下次概率。游戏单机本地存档不承诺防手工改档，但刷新、重复点击或双标签页不能重抽同一次已提交的结果。
- 概率判定在确定性引擎的明确动作中完成：一次尝试的随机结果与资源变动、境界、保底次数、修行记录、修订号作为一个存档事务提交。持久化成功后才能显示成功或失败；持久化失败则保持原档并提示重试。自动化测试须注入可复现的随机源，不用真实概率测试是否“刚好抽中”。

### R35 长期任务与离线结算相容

- 资质改变产速前，先按**旧产速**结算至当前时刻并持久化，再启用新资质。创建新档时无历史收益；旧档升级时的处理见 R36。
- 在途闭关只读开始时锁定的产速；到期奖励不因客户端升级到 v0.6 而回算。新闭关按启动当时的实际产速锁定。持续历练奖励快照与战斗属性完全不受资质或小进阶概率影响。
- 普通离线收益仍受每次最多 12 小时上限约束，天气跨日和镇压复聚继续依 v0.4 分段结算。资质不能让同一离线时段在升级或刷新后结算两次。

### R36 存档升级与旧玩家权益

- 存档 schema 预计由 v4 升至 v5，增加资质 ID、小进阶失败保底计数及必要的尝试记录。v1～v4 旧档自动升级或导入时，资质统一设为**均衡**、保底计数为 0；不按角色五行补随机资质，不改变已有资源、境界、长期任务、每日状态、镇压时间及修行记录。旧玩家不被迫重新建档。
- 升级前保存可恢复原档；迁移与导入先完整校验，后替换现档。v5 导出/导入必须保留资质、保底次数和在途长期任务快照。无效资质、越界保底次数、负资源、损坏任务或版本不兼容时拒绝导入，并保留现档及备份。
- 双标签仍沿用代次与修订号冲突保护。重置后旧标签不得复活旧存档；冲突方读取最新档并提示，不能把新进阶结果覆盖掉。当前引擎与持久化的成功回执规则继续适用。

## 4. 页面、隐私与成本边界

- 创建页显示“随机推荐”“可自行选择”“资质影响的两项产速”，五行选择继续独立；若用户未理解倍率，给一句能读懂的例子，而不暗示某档稀有或更强。
- 修炼页在三次小进阶处展示两种方式的资源门槛、概率和保底进度；资源不足时按钮不可提交且说明缺口。结果面板分列境界变化、修为/灵气实际扣除、下次概率及下一步；人物修仙录可回看失败与成功记录。
- 资质与概率不由 AI 生成或决定；AI 际遇仅使用原有最少上下文，不发送完整存档或新增尝试记录。不新增云资源、账号、推送、付费或模型调用，预计不会增加月度模型费用。
- 本版不扩充筑基后的境界/地图，不做九装备位、随机词条、复杂炼丹、轮回或多人玩法。也不改动天劫的现有结果计算。

## 5. 可执行验收

| 场景 | 必须看到 |
| --- | --- |
| 创建与五行 | 五种灵根都能搭配任意资质；初始推荐可改选；同一资质下五行不会导致不同产速或隐形数值优势。 |
| 产速与离线 | 三种资质的修为/灵气产速与公式一致；升级建筑或换功法后先结旧收益再用新倍率；关闭重开与 12 小时上限不重复结算。 |
| 稳妥与冲关 | 三段小进阶均能选两种方式；稳妥始终成功；用可控随机结果覆盖初次失败、二次失败、第三次保底成功及初次成功，扣费、境界、记录一致。 |
| 资源边界 | 刚好够完整成本可冲关；刚好够稳妥成本可稳妥；不足时显示缺口且无任何扣费；失败仅扣 20%，无负资源。 |
| 存档与并发 | 结果提交后刷新不重抽；双标签并发只成功一次；冲突页刷新后可继续；重置不复活；坏 v5 档不覆盖现档。 |
| 旧档与在途任务 | v1～v4 档升级后资质为均衡、原资源/境界不变；v4 在途闭关按原快照领取；升级后的新闭关按资质产速锁定。 |
| 首次筑基 | 三种资质分别从新档完成现有核心循环直至筑基，稳妥路线可达；对照旧版 45～75 分钟基线记录差异，不把模拟结果冒充真实玩家试玩。 |
| 页面 | 桌面及 360/390/430px、深浅色与减少动效下，创建选择、概率说明、缺口和结果可读可点，底栏不遮挡确认按钮。 |

阶段交付沿用 `AGENTS.md` 的证据包与十项闸门。需提供至少一条真实浏览器闭环、旧档与坏档导入结果、双标签复验、关键页面截图、产品经理照着点的步骤和试玩观察。概率数值先做数学/模拟核对，再由产品经理用少量真实路线试玩评价“有没有想选的理由、失败是否可接受”；无样本时不宣称平衡已验证。

## 6. 已定决策与开发前置条件

1. **产品方向已定**：采用 R33～R36 的可选资质与失败保底作为小范围试玩基线。三种取向可自由选择，旧档保持原强度，稳妥进阶保留必成功路径。
2. **v0.5 闸门待补**：完成真机或等效的全页面移动宽度走查，补前端产物密钥排除与关闭重开/服务重启后的恢复证据，并更新 v0.5 最新证据包和项目状态；若发现新阻塞问题，先修复复验。自然等待到期的领取验证作为非阻塞待办继续记录。
3. **费用与隐私**：不新增模型/云调用，也不改变本地存档与匿名访问边界；现有月度成本上限决策保持不变。
