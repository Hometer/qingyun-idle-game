# 「灵境修行」产品需求文档 v1.0（已确认）

> 起草日期：2026-09-25。依据[已确认的后续版本路线图](../阶段文档/规划/后续版本路线图-v0.6之后.md)起草，聚焦“材料和重复历练所得有什么用途”。内容量与数值已获产品经理确认（“按推荐”）。未被本文明确改写的 v0.2～v0.9 规则继续有效。

## 1. 版本目标与边界

v0.9 之后，灵石、灵草、残页已有去处，但重复历练与秘境所得仍缺一个明确的“造物”出口。v1.0 建立一条**最小炼器闭环**：新增一座「炼器台」，引入一种新材料「玄铁」，用玄铁与现有材料炼制两件固定属性的新装备。

本版建议交付：**一座炼器台 + 一种玄铁 + 两件固定装备配方（精钢剑 / 玄铁甲）**。装备属性固定（沿用确定性战斗），不引入随机词条、强化/分解、九装备位或新货币；玄铁是唯一新增材料。旧装备仍可用、仍可穿戴，存档兼容。

真实玩家试玩与物理真机操作按产品经理既定决定留到最终总体验收。本版开发仍须完成程序模拟、自动测试、浏览器宽度检查、旧档迁移与证据包；未经真人试玩，不宣称平衡或手感已验证。

## 2. 玩家主流程

1. 角色达到筑基一层后，洞府页显示「炼器台」及前置、成本与解锁内容。旧炼丹炉继续炼护劫丹，两者独立。
2. 玩家通过秘境探索获得玄铁（三秘境成功各掉固定数量），或通过镇压持续获得少量玄铁；其余材料沿用现有来源（灵石=镇压/首通，灵草=灵田/秘境，残页=重复战斗/秘境）。
3. 玩家建炼器台后，在背包页炼制精钢剑、玄铁甲。每件展示属性与完整材料清单；材料不足时显示差额，不能提交。
4. 炼制成功装备入背包，可到背包穿戴（沿用现有换装）；重复炼制只增加背包数量，不自动换装。
5. 炼制、换装与资源变动成功持久化后才回执；刷新、导出导入、双标签竞争后结果一致，不能重复扣料或重复获得装备。

## 3. 首轮规则基线

以下数值是供开发模拟的**建议基线**。配置、前端预览、结算和测试须共用同一来源。开发前用 v0.9 可获得的装备与资源余额模拟「不炼器也能通关 v0.9」与「炼器后是否失控」；若新装备让旧地图/秘境/结丹失去意义，应调整数值并在开发文档说明。

### R49 炼器台与玄铁

| 项 | 数值 |
| --- | --- |
| 炼器台 | 洞府建筑，一级；前置筑基一层；成本 灵石 1000、残页 15 |
| 玄铁 | 新材料；来源：灵药谷成功 +2、古修遗迹成功 +3、幽窟险境成功 +5；镇压节点每秒 +0.02 玄铁（每图取当前镇压节点） |

- 炼器台只解锁制作，不自带产速/属性/每日奖励；升级扣费一次提交，重复点击不重复扣费。
- 玄铁是唯一新增材料，不新增货币、不掉落新装备。

### R50 两件固定配方

| 装备 | 部位 | 属性 | 制作成本（玄铁 / 灵石 / 灵草） |
| --- | --- | --- | --- |
| 精钢剑 | 武器 | 攻 +20 | 8 / 800 / 0 |
| 玄铁甲 | 护甲 | 防 +15、护劫减伤 +5% | 12 / 1200 / 30 |

- 两件装备固定属性、不掷随机词条；比现有最强武器（青锋剑攻+15）与护甲（玄铁软甲防+10）略强，换取制作投入。
- 制作前展示属性与材料差额；成功后装备入背包、背包数量 +1，材料只扣一次。旧装备仍保留、仍可穿戴。
- 装备属性进入即时战斗与持续历练快照预览，与 `playerStats`/`predictFight` 一致；不追改已开始任务快照。

## 4. 页面与反馈

- 洞府页：新增「炼器台」卡片（前置、成本、解锁内容）。
- 背包页：炼器区展示两件配方属性、材料清单与差额；「炼制」按钮材料不足时禁用并说明；炼制成功回执列出获得装备。
- 人物页：属性与图鉴回看已获得的新装备；玄铁作为资源在资源栏展示。
- 桌面与 360/390/430px、深浅色、减少动效下可读可点。

## 5. 存档、并发与安全

- 存档 schema 预计 v8→v9：新增炼器台等级、玄铁资源、两件装备 ID。旧档升级：炼器台 0 级、玄铁 0、新装备不赠送，其余保留。升级前有可恢复备份。
- v9 导出/导入保留炼器台等级、玄铁与新装备；坏档（非法炼器台等级、负玄铁、非法装备 ID）拒绝导入并保留现档。
- 建台、炼制、换装沿用代次与修订号保护，双标签只一方成功；扣料、入包、回执同一次持久化提交。
- 不新增模型调用、账号、云资源；AI 仍只写际遇/秘境叙事，不决定装备或制作结果。

## 6. 验收场景

| 场景 | 必须看到 |
| --- | --- |
| 炼器台 | 未筑基不可建；刚好够可建；不足显示差额零扣费；只扣一次、刷新不回归。 |
| 玄铁来源 | 三秘境成功各掉对应玄铁；镇压持续产出；来源与数量可解释。 |
| 炼制 | 两件配方展示属性与材料；不足禁用并说明；炼制后入包、可穿戴、背包 +1、材料只扣一次。 |
| 属性与预览 | 新装备属性进入战斗预估与实战；结丹减伤与 40% 上限照常。 |
| 经济 | 不炼器仍可通关 v0.9；炼器后无失控；材料来源与成本可解释。 |
| 存档与并发 | v1～v8 旧档无损升级；坏档拒绝且现档不变；双标签建台/炼制只成功一次。 |
| 界面 | 桌面与 360/390/430px、深浅色、减少动效可操作。 |

开发交付按 `AGENTS.md` 提供阶段开发文档、自动测试、类型检查、生产构建、浏览器关键闭环、旧档/坏档/并发验证、截图与阶段闸门是否表。真实玩家试玩与物理真机操作届时如未进行，仍如实记“待验”。

## 7. 本版不做与待确认

- 不做九装备位、随机词条、强化/分解、新货币或新掉落表；炼器不扩成抽卡或门派科技树。
- **已确认的范围选择**：按本稿“一座炼器台 + 一种玄铁 + 两件固定装备（精钢剑/玄铁甲）+ R49～R50 首轮数值基线”推进（产品经理 2026-09-25 回复“按推荐”）。
