# 「灵境修行」v1.2 境界体系扩展 PRD（总体范围已确认）

> 产品经理于 2026-09-27 确认：总计 20 个大境界，每境十层，十层即圆满，圆满后才能突破到下一境。本文覆盖境界体系的最终目标与改造约束；当前 v1.1 代码仍只开放至金丹一层，本文不是已实现声明。旧 PRD 中“四界二十一境”以本次“二十境”为准；四界如何划分尚无已确认资料，本版不擅自命名或增加界域规则。

## 1. 玩家问题与目标

当前玩家达到金丹一层后只能回看篇章，无法继续突破。新体系要提供从炼气到鸿蒙道祖的可持续成长主线，同时让每次晋级有可理解的目标。**境界名称和层数是总体规划；能否开放某一境，以该境的历练内容、资源来源、突破试炼和验收证据是否齐备为准。** 不能用空白关卡或单纯增大等待时间冒充可玩内容。

目标玩家、单机网页形态、本地存档、AI 仅写叙事、无 PVP/内购等既定边界继续有效。真人试玩、物理真机、正式部署和新增真实模型验证按产品经理决定留最终总体验收，本地自动化、浏览器和存档验证照常进行。

## 2. 统一境界规则

1. 每个大境界有一层至十层，共 20 × 10 = **200 个层级位置**。十层在 UI 中同时标为“圆满”，例如“金丹十层（金丹圆满）”；圆满不是独立的第十一层。
2. 一至九层之间为小进阶；达到十层后停止同境小进阶，仅能在满足前置条件后主动挑战跨大境界突破。成功进入下一境一层。资源达标不自动突破。
3. 小进阶沿用已确认的“稳妥／冲关、失败保底”原则，具体成本与战斗属性须按全程模拟定基线；跨大境界沿用“条件、消耗、预计结果、失败代价先展示，玩家确认后一次提交”的原则。不同大境界的挑战内容可不同，不把同一段天劫文本复制 19 次。
4. 失败不自动降境界、不丢装备；实际消耗和保底变化必须可回看。任何扣费、判定、境界变化和修仙录记录须一次持久化提交，刷新或双标签竞争不能重复扣费、晋级或领赏。
5. 修炼页始终显示当前“第几境·第几层”、下一步条件和缺口。第 20 境十层是本规划当前终点，仍可继续已有探索、制作和回顾，不自动重置或冒充轮回。

## 4. 每段应有的可玩内容

- 每境至少有一条与该境匹配的历练或探索路线、可获得的成长资源、清晰的下一层目标；一、五、十层分别承担入境、阶段变化和跨境准备的反馈。可复用现有确定性战斗、镇压、长期任务、功法与炼器规则，但敌人、收益和材料用途须随进度可达。
- 每次跨境挑战都要有玩家能准备的条件及可预览结果。筑基天劫和结丹试炼保留其已有事实与战报；后续试炼逐段设计，不把已有护劫丹或旧装备强制改成所有高境界的唯一解。
- 增加境界成本时必须同步模拟三种资质、稳妥/冲关路线、不同装备与功法投入；避免修为/灵气只按指数放大，导致长时间无决策。数值、属性、资源来源、预览与实际结算由同一配置驱动。
- v1.1“金丹篇章”继续作为达到金丹一层的阶段记录，不再暗示人物修行已结束；后续境界可继续记录真实经历，不编造旧档历史。

## 5. 旧档迁移与兼容

当前存档只有炼气一、二、三层、炼气圆满，筑基一、二层、筑基圆满及金丹一层。旧“圆满”须迁移为对应境界十层；金丹一层保持金丹一层。对旧炼气二/三层、筑基二层，开发前依据既有进度、战斗属性和地图门槛制定完整映射表，原则是**不降低已得境界、属性、资源或解锁内容**，不能只把旧 ID 改名。

升级或导入须先校验并保留可恢复备份；坏档拒绝且现档不变。旧修仙录文字、已首通、镇压、秘境次数、装备、建筑、功法、在途长期任务快照和此前突破战报继续保留，不重算已发生结果。新增境界、失败保底及突破记录需通过导出/导入、刷新、双标签竞争与服务重启验证。新版本上线前应能用旧 v1～v9 存档各取代表样例验证迁移。

## 6. 交付顺序与验收

二十境是总目标，实施按连续子阶段提交，每一阶段都要有实际可玩的境界段和独立证据包，不把 200 层空壳一次开放。**首轮开发周期**依次处理：A 旧炼气/筑基十层化及旧档迁移；B 金丹二至十层及对应历练；C “金丹十层→元婴一层”试炼。每段通过本地闸门后继续下一段，再按大境界逐段开放至第二十境。每段的具体成本、地图/试炼数量由 DeepSeek 在阶段开发文档中先给出模拟证据，再编码与验收。

验收至少覆盖：十层与圆满同义、九层不可跨境、十层满足条件可挑战、失败不降境、资源仅扣一次、下一境从一层开始、旧档无损迁移、当前最高已开放境界给出准确提示、未开放境界不出现可点按钮，以及桌面/360/390/430px 的进度与试炼预览。最终真人体验待总体验收时如实标“待验”。
