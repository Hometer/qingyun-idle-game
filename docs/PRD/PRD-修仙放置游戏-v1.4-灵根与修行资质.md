# 《青云修仙录》v1.4 PRD：灵根、先天资质与洗髓

> 2026-09-27。产品经理已确认“灵根定路线、经脉定修炼速度、悟性定学功法成本，修炼侧重由玩家自己定，后天可洗髓”的总体方向。本文是下一版本的开发与验收基线，**游戏代码尚未实现 v1.4**。具体概率、倍率与洗髓费用为首轮配置，编码前须通过全资源模拟；若调整，先记录调整表和原因，再实施。本版承接 [调研稿](../阶段文档/规划/灵根与修行资质重设计-调研稿.md)，v1.3 已提交的内容按仓库实际代码核对，v1.3 尚未通过完整阶段闸门。

## 1. 玩家问题、目标与范围

现有创建页只有金木水火土五个名称；灵根不改变玩法。“均衡／凝神／聚灵”被称为修行资质，却是三个玩家可自由挑的产速取向，无法出现资质好坏，也没有后天改善。这使人物开局缺乏意外与长期身份感。

本版让新人物获得可解释的灵根组合、经脉和悟性；玩家可以决定修炼侧重，也能在长期成长中洗髓。先天差异需要被看见，但不能使低资质角色无法通过稳妥突破、历练和试炼。继续采用单机网页、本地存档、无 PVP、无付费抽取；AI 只写叙事，任何随机概率、产出、成本和战斗结果由确定性代码处理。

本版交付分三个可独立验收的子阶段：A 命盘与先天资质；B 灵根共鸣；C 洗髓。前一子阶段验收未过，不宣布整个 v1.4 完成。不会在本版增加元素功法、五行克制战斗、轮回、账号、服务端抽卡或第 21 境。

### 名词归位

| 名词 | 玩家理解 | 是否随机 | 可否后天变化 |
| --- | --- | --- | --- |
| 灵根 | 五行组合或雷／冰／风变异；决定可启用的共鸣 | 随机鉴灵时随机 | 多灵根可逐次精炼 |
| 经脉 | 吸纳、运转灵气的效率；影响修为与灵气产速 | 随机鉴灵时随机 | 可洗髓提升 |

| 修炼侧重 | 均衡／凝神／聚灵，玩家选择的当前练法 | 不随机强制 | 可手动切换 |

## 2. 创建角色与命盘

### R54 两种开局方式

创建页提供“随机鉴灵”和“自行设定”。随机鉴灵一次生成完整命盘，显示灵根形态与属性、经脉、悟性、可用共鸣、修为／灵气产速、功法费用变化。玩家可以不限次数地重新鉴灵，只有点击“踏入仙途”并成功保存后才创建人物。自行设定可选择灵根形态、具体不重复五行或雷／冰／风、经脉和悟性；主要服务于特定人物设定及低资质挑战。两种方式的游戏规则相同，不给随机方式额外收益。

本地存档无法限制玩家刷新或清档重抽，创建页不声称“每人只抽三次”“稀有保底”或“绝对无法重来”。随机结果不发给模型，不产生费用。随机源支持测试注入；一次创建提交只使用玩家当前确认的命盘，不在提交时暗中再抽。

### R55 灵根池与概率

金木水火土以固定顺序存储；同一组合不重复、不区分排列顺序。单、双、三、四、五灵根分别有 5、10、10、5、1 种组合，另有雷、冰、风三种变异，共 34 种结果。先抽形态，再在该形态内等概率抽具体组合／变异属性。概率公开于创建页帮助说明。

| 形态 | 概率基线 | 例子 | 可启用共鸣 |
| --- | ---: | --- | --- |
| 五灵根 | 12% | 金木水火土 | 五种五行之一 |
| 四灵根 | 18% | 金木水火 | 所含四种之一 |
| 三灵根 | 30% | 金水土 | 所含三种之一 |
| 双灵根 | 25% | 金水 | 所含两种之一 |
| 单灵根 | 10% | 金 | 该元素 |
| 变异灵根 | 5% | 雷／冰／风 | 对应变异共鸣 |

在同一形态内各五行组合等概率；三种变异在变异档内等概率。变异不同时叠加其原生五行共鸣。灵根形态只决定共鸣强度与可选范围，**不再给一个覆盖全部行动的全局产速倍率**。

### R56 经脉与悟性独立随机

两项分别抽取，互不由灵根形态决定；自行设定不使用概率。等级及效果从单一配置读取，不把实际倍率作为可任意篡改的独立存档字段。

| 经脉档 | 概率 | 普通修为和灵气产速 |
| --- | ---: | ---: |
| 闭塞 | 8% | ×0.94 |
| 滞涩 | 22% | ×0.97 |
| 平通 | 40% | ×1.00 |
| 通达 | 22% | ×1.03 |
| 天成 | 8% | ×1.06 |

| 悟性档 | 概率 | 新学习／升级功法的残页费用 |
| --- | ---: | ---: |
| 迟钝 | 8% | 原价 ×1.06 |
| 偏慢 | 22% | 原价 ×1.03 |
| 平常 | 40% | 原价 ×1.00 |
| 聪慧 | 22% | 原价 ×0.97 |
| 通明 | 8% | 原价 ×0.94 |

残页实际费用用 `floor(原价 × 悟性倍率 + 0.5)` 取整，原价为 0 时仍为 0；界面展示原价、调整后费用与缺口。仅新发生的学习和升级按当前悟性计算，已经学会的等级不追缴、不退款。悟性不影响藏经阁建造费、地图掉落、丹药配方、炼器、突破、战斗或天劫。

经脉倍率参与普通在线／离线修为和灵气产出，以及**新开始**闭关时锁定的收益快照。实际产速 = 既有产速公式 × 经脉倍率 × 当前修炼侧重倍率 × 当前火／水共鸣倍率（若启用）；其他建筑、功法、境界和天气规则仍按既有逻辑结算。已有闭关不因洗髓、切换侧重或更新版本而回算。弱经脉不锁任何境界、功法或地图。

### R57 修炼侧重可切换

将 UI 中原“修行资质”改称“修炼侧重”，存档的均衡／凝神／聚灵 ID 与原倍率保持：均衡 1.00／1.00；凝神修为 1.05／灵气 0.95；聚灵修为 0.95／灵气 1.05。创建时选，之后在洞府页手动切换，不收费、不随机。切换动作须先按旧侧重和旧共鸣结算到提交时刻，成功保存后新侧重才生效；关闭重开、离线 12 小时上限、跨日天气、在途闭关和双标签冲突仍正确。当前页应显示两项产速变化的数值预览。

## 3. 灵根共鸣

### R58 五行共鸣

一个人物同一时刻只能启用一项自己灵根所含的共鸣，可在人物页手动切换。切换前结算旧产速并保存；已经开始的长期任务按原快照结束。任何共鸣不限制玩家学习、装备或使用现有功法。

| 灵根形态 | 共鸣强度基线 |
| --- | ---: |
| 单／双／三／四／五 | 5%／4%／3%／2%／1% |

| 共鸣 | 具体效果及生效范围 |
| --- | --- |
| 金 | 地图历练与每日秘境战斗中，对敌最终伤害 ×(1＋强度)，在最终整数伤害前计算；跨境试炼不受影响。 |
| 木 | 已建灵田的灵草每秒产速 ×(1＋强度)；无灵田时不凭空产草。 |
| 水 | 普通修炼灵气每秒产速 ×(1＋强度)。 |
| 火 | 普通修炼修为每秒产速 ×(1＋强度)。 |
| 土 | 地图历练与每日秘境战斗中，受到的最终伤害 ×(1－强度)，在最终整数伤害前计算；跨境试炼不受影响，不改变天劫减伤 40% 上限。 |

战斗效果只在操作提交时按当前共鸣算一次；资源产速随每段结算时间取当时的共鸣。金／土计算须与现有整数伤害取整及至少 1 点伤害规则统一，界面使用同一函数预览，不制造“显示加成但实战永远无变化”的早期假效果。若对某类小伤害取整后无增益，明确显示实际结果。天气、星象和功法仍可叠加，但所有数值只在配置化引擎中决定。

### R59 变异共鸣

雷、冰、风是不同玩法取向，先按以下基线验证，不能只以稀有度推定强于单灵根。

| 变异 | 初拟效果 | 边界 |
| --- | --- | --- |
| 雷 | 玩家主动选择“冲关进阶”时，当前成功率 +4 个百分点，最高 100% | 稳妥进阶仍 100%；失败保底计数与失败扣费规则不变；确认页显示调整前后概率 |
| 冰 | 跨境试炼每波最终伤害 ×0.97，再按现有整数规则结算 | 不改原有减伤 40% 上限、不补血；五波预览与实际一致 |
| 风 | 新开始的持续历练或闭关任务耗时 ×0.96，向上取整到整分钟 | 原选择的 30／60／120 分钟用于奖励和任务展示，实际结束时间按缩短后的分钟数计算；已开始任务的结束时间和奖励快照不改，最低仍需 1 分钟。存档校验须按任务开始时锁定的共鸣版本核对 `endAt`，不能误判 29／58／116 分钟等合法快照 |

变异及五行共鸣在单次战斗、冲关、试炼或长期任务中只读一次已持久化状态，失败重试不得重新抽效果。若验证发现某项永远优于其他根性，应调低或改成有明确取舍的效果，不能偷偷提高所有变异的产速。

## 4. 洗髓与长期成长

### R60 取得与消耗

角色首次到达筑基一层、化神一层、真仙一层、混元金仙一层、天道圣人一层时，各得到一次**可使用的洗髓机会**，共五次；旧高境界存档按已经达到的节点一次性补齐对应机会，不重领。未用机会可保留到以后，既不自动消耗，也不作为新的可购买货币。洗髓需要玩家在人物页预览并确认，AI 不决定结果。

| 所用机会对应的开放境界 | 灵石成本基线 | 灵草成本基线 |
| --- | ---: | ---: |
| 筑基 | 1,000 | 50 |
| 化神 | 10,000 | 200 |
| 真仙 | 100,000 | 1,000 |
| 混元金仙 | 500,000 | 4,000 |
| 天道圣人 | 2,000,000 | 10,000 |

机会按获得时间从早到晚使用；费用随**被使用的机会档**确定，不随当前境界临时涨价，避免玩家存着机会反而被罚。上述费用须与 v1.3 完整材料模拟共同核对；若某一境无法以正常历练、镇压、灵田取得资源，则先调整表，不把洗髓做成必须氪金或无限刷图的任务。余额不足时显示缺口且不扣费。

### R61 三种洗髓选择

每次消耗一次机会，玩家三选一：经脉提升一档；悟性提升一档；非变异且超过一系的灵根移除玩家指定的一种五行，形态随之减少一系、共鸣强度按新形态计算。不能越过最高档，不能把单灵根再减，变异灵根不能用该选项。当前没有可提升项时，机会可保留但不可空耗。改变产速前先结旧收益；在途任务仍用原快照。历史洗髓记录保留原状态、结果、费用和时间，人物页可回看。

低灵根理论上可用四次机会从五灵根逐步精炼到单灵根，但也可把机会花在经脉或悟性上。这是玩家的长期取舍。所有洗髓动作须按存档修订号一次提交，失败、双标签冲突或持久化失败不消耗机会和资源。

## 5. 存档、界面、隐私与成本

### R62 旧存档保护

当前代码存档 schema 为 v14，`spiritRoot` 是一个五行字，`aptitude` 是原三种侧重。后续开发应按子阶段顺次升版并记录字段引入版本，不能假定一切旧档都有新字段。旧档迁移时，经脉设“平通”、悟性设“平常”，旧 `aptitude` 原样转成“修炼侧重”；原单字灵根显示为“旧式灵根”，在用户主动完成一次免费“定根”之前没有新共鸣，也不被自动当作新版单灵根。定根可自行选任意合法灵根结果，确认后一次持久化；它不扣洗髓机会、不改经脉悟性和既有资源。对高境界旧档补已达成的洗髓机会，但不得重复补领。

导入／迁移须校验：五行组合不重复且排序合法、形态与五行数一致、变异只为雷／冰／风、经脉悟性与侧重 ID 合法、当前共鸣属于灵根、已获得机会与境界节点相符、消耗次数不超过获得次数、洗髓历史与现态一致。当前版本缺字段拒绝；真正旧档补默认。自报旧版本但携带新字段时，不能绕过新字段校验。校验失败保留现档与可恢复备份。导出、导入、刷新、浏览器关闭重开和双标签均须保留结果，不重复抽取、重领、洗髓或扣费。

### R63 页面与文案

- **创建页**：先选随机／自设，再看命盘卡。形态概率、两项资质各档概率及效果可展开查看；创建前展示最终修为／灵气产速、功法费用示例和共鸣用途。移动端不摆满 34 个按钮，自设用分步选择。明确随机结果可重抽，且游戏进度仍只存本机。
- **人物页**：显示“灵根／经脉／悟性／修炼侧重”四项，不再把均衡称为高低资质；共鸣选择、洗髓机会与历史在各自解锁后出现。用简短人物描述解释“擅长什么、当前短板、可怎样改变”。
- **修炼、历练、洞府、功法页**：在原产速来路、战前预览、任务时长和功法费用旁显示对应天赋影响；切换侧重和共鸣前后数值可对照。结果面板列出真实扣费、状态变化与下次可做的事。
- **际遇文案**：仅把已经显示给玩家的简短灵根名称作为原 `spirit_root` 上下文发送；不发送经脉、悟性、洗髓历史、抽取记录或完整存档。仅用模板时不发模型请求。AI 不能生成或修改灵根、倍率和结果。

无需新增模型调用、账号、云资源或付费系统；本地运算与存档扩展不增加可计费云资源。正式部署前仍按原项目权限、隐私及安全闸门验收。

## 6. 数值约束与前置验证

[资质敏感度预检](../阶段文档/阶段3-前端/v1.4-资质敏感度预检.md)只复用了理想修为模型。当前代码 `realmProduction.growthPerStage` 仍为 1.22；v1.3 的材料模拟报告指出整体节奏偏快并建议 1.17，尚未在代码中采用。**v1.4 不擅自修改 v1.3 的境界产出系数**，也不拿先天负面倍率修补既有节奏问题。

实施前需以 v1.3 最终通过的全资源模型为基线，纳入灵气、残页、灵石、灵草、洗髓成本、悟性费用、五行共鸣、变异效果、每日一次／两次登录及 12 小时离线上限。至少比较：最弱与最强经脉／悟性组合、火水单根、五杂灵根、雷冰风、旧档定根、洗髓与不洗髓。目标仍沿用已定的全程 42～56 天普通玩家口径；一次和两次登录要分别报告，若 v1.3 本身不满足目标，先归因并单列修正，不能把两版收益混算为 v1.4 的效果。任一低天赋档都必须能走稳妥路线通关；相同登录习惯和同类决策下，初始天赋导致的总用时差建议不超过 20%，超出则先缩小数值差。

## 8. 产品经理验收路径

1. 打开本地创建页，分别试“随机鉴灵”和“自行设定”。看到相同灵根形态也能有不同经脉、悟性；五杂与单根的共鸣选择数量不同，变异有专属用途。
2. 以“闭塞经脉＋通明悟性”建角，查看修为／灵气产速和功法费用，再换成高经脉／低悟性新档对照；两种角色都能继续历练和稳妥突破。
3. 在洞府切换均衡／凝神／聚灵，在人物页切换可用共鸣；确认产速、战斗预览或任务时长的变化，并在刷新后仍保持所选状态。
4. 筑基后查看洗髓费用和三种结果，只确认其中一种；确认资源和机会只扣一次，记录可回看。旧档导入后确认原资源、境界、功法、装备和在途任务不变，再自愿定根。
