# 「青云修仙录」产品需求文档 v0.4

> 范围修订：2026-09-24。本文按已提交的 v0.4 范围对齐与修复方案同步需求基线。产品经理已表示 v0.4 复核完成；独立浏览器复验证据与阶段闸门仍以证据包为准。

## 1. 版本定位

v0.4 在 v0.3 的即时战斗与修炼闭环上增加三个回访机制：每日目标、天气与星象、镇压复聚。规则保持确定性，不强制打卡，AI 不参与奖励或状态判定。未在本文改动的 v0.2、v0.3 规则继续有效。

## 2. 功能需求

### 2.1 每日目标（R18）

- 每天固定两项可选目标，不随机抽取：完成 3 次战斗，奖励残页 +3；镇压 1 个节点，奖励灵石 +40。
- 进度随玩家操作累计，达标后显示“可领取”。玩家手动领取才发放奖励，不自动发放；同一目标每天只可领取一次。
- 跨天按本地日期重置进度和领取状态。前一天已达标但未领取的奖励作废，不补发；不处罚未参与的玩家。
- 目标入口显示条件、当前进度、奖励和领取状态。刷新、重进及双标签操作不能丢失进度或重复领奖。

### 2.2 天气与星象（R19）

天气与星象每日各确定性选出一种，分开展示并分别记录今日限次使用状态；跨天重置，互不影响。

| 类型 | 当日效果 | 触发与次数 |
| --- | --- | --- |
| 天气·灵雨 | 灵草 +30 | 今日首次领取收益，一次 |
| 天气·晴明 | 修为 +100 | 今日首次领取收益，一次 |
| 天气·灵脉涌 | 灵石 +80 | 今日首次领取收益，一次 |
| 天气·平常 | 无额外奖励 | 无 |
| 星象·吉星 | 修为 +50 | 今日首次战斗胜利，一次 |
| 星象·破军 | 最终战斗伤害 +20%，按既有取整规则结算 | 今日首次战斗，一次 |
| 星象·平常 | 无额外效果 | 无 |

- 有限次奖励必须进入实际结算和存档，界面预览、待领取数字与到账结果一致；已用过的天气或星象不再触发。
- 离线跨天结算按日期分段，不能把新一天的加成套到前一天。天气与星象不改变渡劫、固定进阶成功规则或 AI 际遇奖励。
- “首次领取收益”是否消耗天气限次，以引擎成功提交该次领取为准；失败或刷新不消耗。破军的预览与实战使用同一最终伤害公式。

### 2.3 镇压复聚（R20）

- 每张地图独立计算镇压；一次镇压持续 **24 小时**，到期该图妖气复聚，镇压产出停止，节点回到“已通关、未镇压”。玩家可以再战并重新镇压。
- 节点详情和历练页显示该图剩余时间；到期由存档时间戳判定，不依赖页面常开或定时器。
- 跨越到期点的离线收益须分段结算：到期前的有效镇压收益保留，到期后该图镇压速率为零。另一张地图的镇压不受影响。
- 旧档若已有活跃镇压但没有开始时间，迁移时按旧档 lastSettledAt 作为起点补齐；不能出现“镇压中但剩余 0 小时且永不复聚”。

## 3. 存档、兼容与错误处理

1. 存档 schema 为 v3。daily 保存日期、天气/星象的 ID 与限次状态、两项目标的进度与领取状态；suppressionSince 保存每张地图的镇压起始时间。
2. v1、v2、v3 旧档导入时均须先校验、备份现档，再迁移或覆盖；失败时原档可恢复且现档不被坏档覆盖。旧档已有的资源、境界、地图进度和镇压状态应保留。
3. 校验每日记录的日期、任务 ID、进度范围及镇压时间戳与当前镇压状态；损坏存档给出可理解的错误，不进入半损坏状态。
4. 领奖、天气与星象限次、复聚和收益到账均由确定性引擎处理。双标签竞争采用存档修订号校验，失败方重新读取，不能重复领奖或覆盖另一方操作。

## 4. 验收场景

| 场景 | 必须看到 |
| --- | --- |
| 每日目标 | 固定两项；战斗 3 次和镇压 1 次各自达标后需手动领取；重复点击只到账一次；跨天未领取作废。 |
| 天气与星象 | 分别显示当日效果与是否已用；天气仅首次收益领取生效，星象仅对应首次战斗生效；预览、到账、存档一致。 |
| 跨天结算 | 离线跨越日期时按日期与限次状态处理，旧时段不套新一天效果。 |
| 镇压复聚 | 每图 24 小时；到期前收益完整、到期后停止；两图独立；复聚后可再战再镇压。 |
| 旧档与坏档 | v1/v2/v3 档可导入并保留进度；坏 v3 档被拒绝，原档和现档均可恢复。 |
| 刷新与双标签 | 刷新后进度和限次状态不丢；并发领取不重复发奖；窄屏与桌面可操作。 |

开发验收须补独立浏览器复验、旧档导入、跨天与到期场景、关键截图及阶段闸门是否表。自动化测试通过不能替代这些证据。

## 5. 本版不做

随机资质、概率小进阶、持续历练与闭关倒计时、九装备位、随机词条、复杂炼丹、师承/道侣/灵兽/寿元/轮回、账号/PVP/内购。持续历练与闭关进入 v0.5 待审阅范围。
