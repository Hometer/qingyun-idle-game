# 「青云修仙录」产品需求文档 v0.4

> 状态：范围已确认（每日任务、天气与星象、镇压复聚三项全做）。承接 v0.3，新增三项回访/循环机制，不改 v0.3 已定的核心规则与数值基线。

## 1. 版本定位

v0.3 已让"每一步看得懂"。v0.4 解决"为什么明天还回来"：给回访一个理由（每日任务）、给每天一点变化（天气星象）、给历练一个循环（镇压复聚）。

三项均为**新规则**，但遵守同一原则：确定性、可配置、不强制打卡、AI 不参与规则判定。

## 2. 功能需求

### 2.1 每日任务（R18）

- 每天生成 **3 个可选任务**，由日期确定性选择（同一天所有玩家看到同一组），不需要服务端。
- 任务池（首轮）：
  1. 领取一次收益
  2. 完成一次小进阶
  3. 完成 3 次战斗
  4. 镇压一个节点
  5. 炼制一枚护劫丹
  6. 完成一次际遇
- 每个任务有：标题、条件说明、进度（当前/目标）、固定奖励（灵石/灵草/残页/修为）。
- 完成即自动发放奖励并标记；不发重复奖励。跨天自动换新任务，旧任务状态丢弃（不补发）。
- 不强制、不惩罚；奖励量小（如灵石 20~50），不破坏 v0.3 经济。
- 任务进度与完成状态随操作一起持久化，刷新/重进不丢。
- 人物页或顶部有每日任务入口，显示今日任务与进度；完成后可回看当日结果。

### 2.2 天气与星象（R19）

- 每天一个"天时"加成，由日期确定性选择，全天生效，展示在页头。
- 效果池（首轮 5 种，等概率轮换）：
  | 天时 | 效果 |
  | --- | --- |
  | 晴明 | 修为/灵气产出 +15% |
  | 灵雨 | 灵草产出 +50% |
  | 灵脉涌 | 灵石（镇压）产出 +30% |
  | 杀伐 | 战斗伤害 +10% |
  | 平常 | 无加成 |
- 加成**只作用于产出或战斗伤害**，作用于同一套确定性计算（预览与实际一致），不改变渡劫、进阶门槛、际遇奖励。
- 天时不影响存档数值正确性；旧档升级后按当天日期正常显示。

### 2.3 镇压复聚（R20）

- 镇压一个节点后，其产出持续 **12 小时**（可配置），到期后"妖气复聚"，镇压自动失效，产出停止。
- 复聚后节点回到"已通关、未镇压"状态，玩家可再次战斗（获得重复奖励）并重新镇压。
- 复聚结算在读取/操作存档时按时间差进行（同离线结算），不依赖常驻定时器；复聚发生时给出提示。
- 节点详情与历练页显示镇压剩余时间；切换镇压目标不影响已结算的过去收益。

## 3. 数据与兼容

1. 存档 schema 升级到 v3，新增：`daily`（今日任务/计数）、`suppressionSince`（各图镇压起始时间）。天气由日期派生，不落存档。
2. v0.2 / v0.3 存档均可无损升级到 v4 规则：迁移前备份原档、失败保留原档；旧档的 `daily` 按当天生成、`suppressionSince` 按当前镇压状态补一个"已到期"或"从今起算"的合理值。
3. 每日任务进度、镇压起止时间随操作持久化，刷新/重启/多标签页不丢失、不重复发奖。
4. 所有新规则由确定性代码判定，AI 不参与任务/天时/复聚的判断与奖励。

## 4. 验收场景

| 场景 | 必须看到 |
| --- | --- |
| 每日任务 | 当天显示 3 个任务与进度；完成即发奖励、标记；跨天换新任务；刷新不重复发。 |
| 天气星象 | 页头显示当天加成；产出/战斗伤害按加成变化；预览与实际一致；渡劫/进阶不受影响。 |
| 镇压复聚 | 镇压后显示剩余时间；到期自动失效并提示；可再战再镇压；过去收益不重算。 |
| 旧档升级 | v0.2/v0.3 档迁入后进度、资源、境界、镇压保留；任务按当天生成。 |

以上同时检查刷新恢复、多标签页不重复发奖、窄屏与桌面可操作，界面显示与引擎结果一致。

## 5. 本版不做

随机资质、概率小进阶、持续历练、九装备位、随机词条、复杂炼丹、师承/道侣/灵兽/寿元/轮回、账号/PVP/内购。
