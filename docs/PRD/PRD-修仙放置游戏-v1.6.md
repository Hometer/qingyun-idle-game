# 青云修仙录 v1.6：装备词条、重铸与封存

状态：产品经理已确认范围，2026-09-27。

## 1. 要解决的问题

装备目前只有攻击、防御、气血、护劫减伤等基础属性，一件装备大多只有一两条，没有可比较、可追求的随机差异。装备详情缺少词条、换装对比与长期养成目标。

## 2. 玩家体验

1. 每件新取得的装备带 1~4 条随机词条；基础属性稳定，词条提供可选提升。
2. 词条分基础与特殊两类：基础为攻击、防御、气血、战斗伤害、受伤减免、修为产速、灵气产速；特殊为暴击率、突破率、每回合回血、低血增伤、战斗所得修为。
3. 装备详情展示品阶、基础属性、全部词条、来源，以及穿上后的攻防血/产速变化；同名装备因获得顺序不同可带不同词条。
4. 重铸：重新随机该装备词条，展示费用与新旧结果；锁定词条在重铸时保留，锁定后重铸费用提高。
5. 封存：最多锁定 1 条词条，可解锁；锁定/解锁各收一次费。

## 3. 词条数值（首轮，可调）

| 词条 | 类别 | 范围 | 说明 |
| --- | --- | --- | --- |
| 攻击 | 基础 | +2~+10 | 固定值 |
| 防御 | 基础 | +1~+5 | 固定值 |
| 气血 | 基础 | +10~+50 | 固定值 |
| 战斗伤害 | 基础 | +2%~+8% | 对敌最终伤害 × |
| 受伤减免 | 基础 | −2%~−8% | 受击伤害 × |
| 修为产速 | 基础 | +2%~+8% | 普通修炼 |
| 灵气产速 | 基础 | +2%~+8% | 普通修炼 |
| 暴击率 | 特殊 | +2%~+10% | 攻击概率伤害 ×1.5 |
| 突破率 | 特殊 | +1%~+5% | 冲关进阶成功率 +百分点 |
| 每回合回血 | 特殊 | +2~+10 | 每回合恢复 |
| 低血增伤 | 特殊 | +5%~+15% | 气血低于 30% 时伤害 + |

条数随境界：筑基前 1 条，第 2~7 境最多 2 条，第 8~15 境最多 3 条，第 16~20 境最多 4 条。

## 4. 重铸与封存

- 重铸费用：灵石 500 + 玄铁 20（有锁定词条时 ×1.5）。
- 锁定费用：灵石 1000 + 玄铁 50；解锁免费。
- 只消耗现有灵石、玄铁；不新增货币；不销毁装备。

## 5. 边界

- 守关与跨境试炼不要求抽到稀有词条；普通装备可通关。
- 所有效果由配置与确定性结算代码执行；AI 只写叙事，不生成属性或奖励。
- 词条生成用确定性伪随机（装备 ID 哈希 + 获得序号），保证测试可复现。

## 6. 存档与兼容

- `equipmentAffixes`（各装备词条）、`lockedAffixes`（锁定词条）入档，schema v16。
- 旧档迁移：已有装备补空词条，不影响现有存档；坏档拒绝且当前档不变。
- 重铸/锁定/解锁双标签只成功一次；刷新后结果保持。

## 7. 交付与验收

- 分两阶段：A 装备词条 + 生成 + 详情；B 重铸 + 封存。
- 验收：词条展示与结算一致；特殊词条在战报/产速中体现；重铸锁定词条保留、费用正确；坏档拒绝；前端测试 + typecheck/lint/build 通过。真人试玩与真机标「待验」。
