# 「青云修仙录」产品需求文档 v0.8（已确认）

> 起草日期：2026-09-25。依据[已确认的后续版本路线图](../阶段文档/规划/后续版本路线图-v0.6之后.md)与[v0.7 最终独立复核](../evidence/阶段3-v0.7最终复核/验收说明.md)起草。内容量与数值已获产品经理确认（“按推荐”）。未被本文明确改写的 v0.2～v0.7 规则继续有效。

## 1. 版本目标与边界

v0.7 已打通筑基一层至金丹一层。玩家现在可以升级两本旧功法，但同一时刻只能主修一本；修为产速与护劫减伤之间的切换容易理解，历练战斗与灵气积累却缺少对应的功法取向。v0.8 要让玩家在新成长段形成**速修、聚灵、历练、护劫**几种看得见来路的选择，并能同时主修和辅修不同功法。选择须体现在产速、战斗或试炼预览中；不增加概率战斗、随机词条或新的付费资源。

本版建议交付：**一座两级藏经阁、两本新功法、一个辅修位，以及现有两本功法的辅修效果**。藏经阁是洞府中的选择入口，不是新的挂机产出建筑。金丹一层仍是当前主线终点；本版让已达金丹的旧玩家有新培养目标，也让筑基玩家能在 v0.7 主线中使用新取向。无藏经阁的旧路线仍能通关 v0.7，不能把新增系统变成强制补课。

真实玩家试玩与物理真机操作按产品经理既定决定留到最终总体验收。本版开发仍须完成程序模拟、自动测试、浏览器宽度检查、旧档迁移与证据包；未经真人试玩，不宣称平衡性或操作手感已验证。

## 2. 玩家主流程

1. 角色到筑基一层后，在洞府看到藏经阁的两级用途、成本及当前缺口。建成一级可研习两本新功法；原有青云诀、玄龟诀的主修入口与等级不变。
2. 玩家选择主修功法并升级。修炼页展示当前修为/灵气产速、攻防气血与护劫减伤的来源；历练与结丹预览跟随当前主修变化。
3. 藏经阁升到二级后开放一个辅修位。玩家可辅修与主修**不同**的一本已开放功法，获得该功法较弱的效果。界面先展示切换前后的关键数值；辅修可随时调整，不额外收费。
4. 玩家可走资源积累路线，也可走战斗准备路线推进云岭古道；结丹前仍可改用玄龟诀准备试炼。切换先结算旧产速，再启用新功法。已开始的闭关/持续历练继续使用启动时快照。
5. 升级藏经阁、研习/升级功法、主辅切换与资源变化均成功持久化后才回执；刷新、导出导入与双标签竞争后仍是一份结果。

## 3. 首轮规则基线

以下数值是供开发模拟的**建议基线**，不是最终平衡结论。配置、前端预览、结算和测试须共用同一来源。开发前先以 v0.7 可获得的装备、三种资质和典型资源余额模拟两条路线；若数值使某条路线无法完成或一条路线在所有目标上严格占优，应在开发文档说明调整理由，再更新本表并请产品经理审阅。

### R41 藏经阁与解锁

| 等级 | 前置 | 一次性成本 | 解锁内容 |
| --- | --- | --- | --- |
| 未建 | 无 | 无 | 旧青云诀、玄龟诀照常主修；无辅修 |
| 一级 | 筑基一层及以上 | 灵石 800、残页 10 | 可主修新功法破岳诀、聚元诀 |
| 二级 | 已建一级 | 灵石 1600、残页 20 | 开放一个辅修位；四本已开放功法可作为辅修 |

- 藏经阁只解锁选择，不自带产速、战斗属性或每日奖励；不新增第三等级。升级需同时满足灵石与残页，扣费与等级变化一次提交，重复点击不得重复扣费。旧地图重复战斗和既有每日目标仍是残页来源，新旧地图镇压仍是灵石来源；本版不造专用“功法券”。
- 玩家可选择先攒灵石结丹，也可先建藏经阁改善修行；结丹试炼不以藏经阁等级为前置。已到金丹一层的旧角色也可直接建阁，不回滚境界或重做首通。

### R42 功法、主修与辅修

新功法与旧功法共用 Lv1～Lv3：首次选择尚未研习的功法，按现有规则免费学到 Lv1；从 Lv1→Lv2 消耗残页 5，从 Lv2→Lv3 消耗残页 15。已投入的等级属于**这本功法**，换主辅位不重买、不降级、不退费。两本旧功法原等级与效果完整保留。

| 功法 | 取向 | Lv1/Lv2/Lv3 主修效果 | Lv1/Lv2/Lv3 辅修效果 |
| --- | --- | --- | --- |
| 青云诀（已有） | 修为积累 | 修为产速 ×1.30 / ×1.60 / ×2.00（沿用） | 修为产速 ×1.15 / ×1.30 / ×1.50 |
| 玄龟诀（已有） | 护劫准备 | 天劫、结丹减伤 +5% / +10% / +15%（沿用） | 天劫、结丹减伤 +2.5% / +5% / +7.5% |
| 破岳诀（新增） | 历练战斗 | 玩家攻击 +4 / +8 / +12 | 玩家攻击 +2 / +4 / +6 |
| 聚元诀（新增） | 灵气积累 | 灵气产速 ×1.15 / ×1.30 / ×1.50 | 灵气产速 ×1.075 / ×1.15 / ×1.25 |

- 同一时刻最多一本主修、一本辅修，不能同一本占两个位置。把当前辅修改为主修时，**主辅互换**并在确认前展示两项变化；反向操作同理。没有主修时不能单独设置辅修。可随时调整，除首次学到 Lv1 和升级所需残页外不收切换费、不设冷却；旧主修切换习惯保持可用。
- 修为产速 = 现有基础值 × 资质 × 修炼室 × 当前青云诀主修或辅修倍率；灵气产速 = 现有基础值 × 资质 × 聚灵阵 × 当前聚元诀主修或辅修倍率。一本功法未上槽时无被动效果。青云诀与聚元诀各只可能占一个槽位，不能同书叠乘；现有离线 12 小时上限不变。
- 破岳诀攻击加成与境界、装备加成相加，进入即时战斗预估与**新开始**的持续历练快照；不改变敌人属性、掉落或隐藏命中率。玄龟诀的主/辅减伤与装备减伤相加，继续受 40% 总上限约束；结丹与旧天劫每波仍按既有公式向上取整。防御、最大气血与护劫丹规则不变。
- 切换任何影响产速的功法前先按旧配置结算至切换时刻并持久化，再启用新配置；不能用新倍率补领旧时段收益。既有战报、首通结果和进行中的长期任务快照不重算。预览与真正执行使用同一配置和取整规则。

### R43 清楚的取舍与可达性

- **资源路线**示例：主修青云诀、辅修聚元诀，优先积累修为和灵气；云岭古道继续用现有装备通关，结丹前可互换/改修玄龟诀。**历练路线**示例：主修破岳诀、辅修青云诀，降低同一节点的战斗回合或所需装备准备；资源产速低于资源路线，结丹仍按实际减伤准备。玄龟诀主修则是直接偏护劫的第三种选择。
- 至少以“同一资质、境界、装备、功法等级投资”比较资源路线与历练路线：前者有更高的相关每秒资源收入，后者在云岭第三节点有更高攻击且不降低生存数据。两条路线均能用 v0.7 已有装备和资源来源到达金丹一层；若需换功法，模拟须计入实际残页与切换步骤。不得以 v0.9 秘境或 v1.0 炼器补足可达性。
- 不把“某一套当前装配对所有产速、节点胜率与试炼余血都最优”作为目标。若模拟发现某套无代价地同时胜出，应收窄效果或成本，而非加入随机失败惩罚。真人试玩最终决定是否真有选择意愿，程序模拟只证明规则自洽和可达。

### R44 页面与反馈

- **洞府页**：藏经阁展示前置境界、当前等级、两级成本、尚缺资源和解锁内容；升级成功后显示本次扣费与新开放的选择。原四栋建筑和等级不变。
- **修炼页**：四本功法卡片展示“未解锁/未研习/当前 Lv/主修/辅修”、主辅具体效果和下级残页成本。当前配置旁同时显示修为、灵气产速、攻击、护劫减伤的**数值来路**。切换前比较原配置与新配置；同书主辅互换时给出明确提示。结丹五波、丹药和缺口展示沿用 v0.7 的已修复状态。
- **人物页与修仙录**：人物属性显示破岳诀攻击来源；修仙录只记录实际完成的藏经阁升级、功法研习/升级和首次采用辅修，不凭空补写旧档历史。可回看当前主辅配置及各书等级；不为每次免费切换刷大量日志。
- 桌面及 360/390/430px 宽度下，四书主辅、成本、来源与切换预览可读可点；深浅色与减少动效继续可用。物理真机操作仍留总体验收。

### R45 存档、并发与边界

- 存档 schema 预计 v6→v7，新增藏经阁等级、辅修功法 ID，以及破岳诀/聚元诀等级。v1～v6 旧档升级：藏经阁为 0、辅修为空、新功法等级为 0；旧主修、旧书等级、资质、资源、境界、地图、镇压、每日状态、修仙录及在途任务全部保留。升级前有可恢复备份；新版本不修改已开始任务快照。
- v7 导出/导入完整保留新字段。无效藏经阁等级、未解锁却选用新功法、辅修与主修同书、无主修却有辅修、非法等级/负资源或损坏任务须拒绝导入并保留现档；旧版本缺新字段按其版本规则迁移。新客户端不承诺 v7 存档可被旧客户端直接读取。
- 建阁、研习、升级、切换主辅都沿用代次与修订号保护。双标签只允许一方成功提交，另一方读取最新存档并提示；扣资源、变等级、切槽位和修订号必须在同一次持久化写入，失败不显示成功回执。
- 不新增模型调用、账号或云资源；AI 仍只写既有际遇文案，不接收完整功法配置来决定战斗或收益。本版预计不增加月度模型费用，沿用本地存档与现有隐私边界。

## 4. 验收场景

| 场景 | 必须看到 |
| --- | --- |
| 旧档续玩 | v6 筑基一层和金丹一层旧档都无损升级；旧功法与资源、地图、结丹战报、在途任务不变；不建阁仍能继续旧玩法。 |
| 藏经阁两级 | 境界未达不可建；刚好够灵石与残页可升级；不足给差额且零扣费；各级只扣一次、刷新后等级不回退。 |
| 四书主辅 | 新书一级解锁、二三级成本正确；旧书原等级不变；同书不能双槽；主辅互换或换书后预览与实际相同，免费切换不丢等级。 |
| 资源和时间 | 青云/聚元主辅、资质与建筑计算一致；挂机跨门槛显示与按钮同步；切换时旧时段按旧倍率结算，新时段按新倍率；12 小时封顶不重算。 |
| 战斗与试炼 | 破岳攻击改变同一节点的预估与实际回合；玄龟主/辅、装备减伤及 40% 上限一致；结丹五波预览与实战一致，已开始任务快照不变。 |
| 两种路线 | 同等投入下资源路线与历练路线各有可解释优势，均可通关至金丹；记录三种资质的程序模拟，不把模拟当真人试玩。 |
| 存档与并发 | v1～v6 合法档迁移，v7 导出导入保留主辅与阁等级；坏档拒绝且现档不变；双标签建阁/换书/升级只提交一次。 |
| 界面 | 桌面与 360/390/430px、深浅色和减少动效下，成本、来源、切换预览、确认与结果可读可操作。 |

开发交付按 `AGENTS.md` 提供阶段开发文档、自动测试、类型检查、生产构建、浏览器关键闭环、旧档/坏档/并发验证、截图、操作步骤及阶段闸门是否表。真实玩家试玩与物理真机操作届时如未进行，仍如实记“待验”。

## 5. 本版不做与待确认

- 不做多存档位、宗门、灵兽、道侣、寿元轮回或账号；不做 v0.9 的秘境/新际遇，也不做 v1.0 的炼器、随机词条与新装备位。藏经阁不扩成大规模抽书、门派科技树或被动全书加成。
- **已确认的范围选择**：按本稿“两级藏经阁 + 两本新功法 + 一个辅修位”及 R41～R42 首轮成本/效果基线推进（产品经理 2026-09-25 回复“按推荐”）。
