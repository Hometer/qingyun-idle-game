# 配置说明

编辑 `backend/.env`。`MODEL_API_KEY` 留空也能玩，际遇会使用模板。真实模型费用按 Token 估算并由本地账本限制；金额上限不能替代供应商账单。

| 配置 | 位置 | 作用 |
| --- | --- | --- |
| MODEL_API_KEY / MODEL_API_BASE / MODEL_NAME | 后端 `.env` | Key 留空使用模板；默认 DeepSeek 兼容端点 |
| ACCESS_CODE / ENVIRONMENT | 后端 `.env` | 公网 production 模式要求访问码；本仓库以本地运行说明为准 |
| MONTHLY_BUDGET_RMB | 后端 `.env` | 月度费用估算上限，标价也需核对 |
| NEXT_PUBLIC_BACKEND_URL | 前端构建环境 | 默认 `http://localhost:8001`，仅放服务地址 |

## 本机数据与验证

`frontend/` 为 Next.js 与 TypeScript 游戏引擎，`backend/` 为 FastAPI 文案代理。玩家进度保存在浏览器 IndexedDB，换设备前请导出存档。

各项目端口可能重叠，分别运行时先停止自己启动的前一项目，或按各项目配置调整端口与代理。密钥、业务数据、模型文件、依赖和构建产物留在本机，不进入公开仓库。克隆仓库不会带入原电脑的模型配置、邀请码数据库或费用额度。

## 工程检查

以下为离线工程检查入口；历史真实模型脚本可能产生费用，请先阅读对应验收记录。

```bash
(cd backend && .venv/bin/python -m pytest -q)
npm --prefix frontend test
npm --prefix frontend run typecheck
npm --prefix frontend run lint
npm --prefix frontend run build
```

本次 GitHub 整理不追加真实模型调用，也不改变产品阶段验收结论。历史开发过程见 [开发记录](历史/开发记录.md)。
